# 持盈止损卖出框架（拐点止盈 + 看错止损）

## R — 原文 (Reading)

> "截断亏损，让利润奔跑。盈利的时候要拿住，不能见小利就落袋为安……几乎所有超级成长股在涨10倍过程中都会经历2次左右30%-40%中期调整……只要基本面没有拐点，就坚定持有。如果发现自己逻辑看错了，或者公司基本面出现向下拐点，无论浮亏多少，必须坚决砍仓。卖出的唯一核心依据，是基本面出现拐点。不要试图逃顶——超级成长股顶部只有一个，你逃顶千次大概率只对一次。卖飞比套牢更致命。"
>
> — 静水2008，第三章 第10-11节

---

## I — 方法论骨架 (Interpretation)

这是一套**不对称**的卖出纪律，把"何时卖"完全挂在基本面上、与价格脱钩。

1. **盈利侧默认不卖**：以"不卖"的心态持有牛股，接受涨10倍途中2次左右30%-40%的正常回撤，甚至单票腰斩。回撤是噪音，不是卖出信号。
2. **止盈只有一条触发**：基本面出现向下拐点（行业增速下滑、业绩不及预期、核心成长逻辑被破坏），且拐点靠财报"清晰展现"而非主观猜顶——不逃顶。
3. **止损也只有一条触发**：买入逻辑看错（标的不该买），或基本面出现向下拐点。无论浮亏多少、多疼，立即砍仓，壮士断腕。
4. **越亏越补是致命恶习**：补仓只允许在"景气度不变"下（见相邻 skill），基本面恶化时补仓=把小亏拖成大亏。
5. **不对称的底层逻辑**：卖飞主升浪的期望值损失，远大于偶尔躲回撤的收益；顶部唯一，逃顶千次只对一次。

核心是把"卖不卖"从情绪题（落袋为安/舍不得割）转成事实判断题：**基本面拐了吗？逻辑看错了吗？** 没有就死拿，有就砍。

## A1 — 书中的应用 (Past Application)

### 案例 1：19-20年"吃药喝酒"——景气不变就死拿、躺赚5-10倍（c01）

- **问题**：用户持有一只超级成长股，浮盈出现，是否该止盈落袋？
- **方法论的使用**：作者把19-20年白酒/医药定义为"对应阶段的价值投资主线"，是当时最景气的超级成长股。按持盈不止盈纪律，只要景气度（行业增速/业绩/成长逻辑）不变，就应躺在其上死拿，接受涨10倍途中的2次30%-40%回撤。
- **结论**：盈利侧默认"不卖"，以不卖心态持有，直到基本面出现向下拐点才止盈。
- **结果**：当年躺在白酒/医药10倍股上的真价投收获5-10倍收益；而"赚20%就跑"者卖飞了后面数倍的主升浪。

### 案例 2：行业去库周期中白酒被不停抄底——基本面拐点了还死扛=伪价投（c02）

- **问题**：持有的白酒股持续下跌，要不要"越跌越补摊平成本"、以"长期持有"自我安慰？
- **方法论的使用**：作者明确白酒进入去库周期、业绩持续下滑=基本面已出现向下拐点。此时该做的是止损砍仓（拐点已现），而非越跌越补。越亏越补在景气不变的标的上正确，在基本面恶化的标的上是加速亏损。
- **结论**：拐点出现→止盈止损立即触发；越亏越补/摊平成本是致命恶习；用"长期持有"包装死扛是伪价值投资。
- **结果**：作者断言此类"伪价投"必然亏钱，是绝大多数人打着价投旗号亏钱的总根源。这说明同一只白酒股，景气不变时（19-20）该死拿、景气拐点后（去库周期）该砍——卖出动作完全由基本面拐点决定，与价格无关。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **浮盈焦虑型**：持仓盈利20%-50%，看到浮盈开始回撤，纠结"要不要止盈落袋为安""已经赚了要不要先卖一半"。
2. **回撤恐慌型**：持仓出现30%-40%甚至腰斩级的回撤，但买入逻辑自己还说不太清，纠结"是不是该卖了止损""还是再扛扛"。
3. **浮亏摊平型**：持仓浮亏，第一反应是"跌这么多了再补一点摊低成本"，而不是先问"基本面拐没拐、卖出的人为什么卖"。
4. **逃顶幻想型**：持仓大涨，反复琢磨"是不是见顶了""要不要先逃顶躲一波回撤再接回来"。
5. **逻辑动摇型**：持仓的公司刚发了财报或出了新闻，业绩/景气/逻辑似乎有变化，需要判断这算不算"基本面拐点"、要不要据此卖出。

### 语言信号 (用户的话里出现这些就应激活)

- "盈利X%了要不要止盈 / 该不该落袋为安 / 锁定收益"
- "Take profit? Lock in gains? Sell winners?"
- "回撤好大要不要卖 / 涨太多该逃顶了吧"
- "Drawdown too big, should I sell? Call the top?"
- "浮亏了，要不要补仓摊平成本 / 越跌越买"
- "Average down? Buy more to lower cost?"
- "舍不得割 / 死扛 / 没卖就不算亏"
- "Stuck / underwater, can't bring myself to cut"
- "我总是卖早 / 卖飞了 / 错过主升浪"
- "Sold too early, missed the rally"

### 与相邻 skill 的区分（初稿，阶段 3 回填定稿）

- **与 `prosperity-and-inflection`（景气度与拐点判断）的区别**：那个 skill 解决"拐点到了吗/景气度变了吗"的**识别**问题；本 skill 解决"识别出拐点（或看错）后**怎么卖、卖不卖**"的**执行**问题。本 skill 的卖出触发**依赖**那个 skill 先判出拐点。如果用户还没确认拐点，先调那个 skill。
- **与 `scale-in-and-risk-control`（回调分仓买入 + 仓位风控）的区别**：那个 skill 管的是**买入侧**和**仓位结构**（回调分批、两条红线、越跌越买的边界=景气度不变）；本 skill 管的是**持有与卖出侧**（持盈、拐点止盈、看错止损）。两者在"越跌越补"上有交接面：那个 skill 判断"能不能补"，本 skill 判断"该不该砍/该不该卖"。
- **与 `real-vs-fake-value-investing`（真假价值投资辨析）的区别**：那个 skill 解决"我这套到底算不算价投、是不是伪价投"的**身份/路径**判断；伪价投（景气向下还死扛）是本 skill B 段的核心反场景来源，但本 skill 聚焦**卖出动作纪律**本身。若用户问题是"我长期持有却一直亏，算价投吗"，先调那个 skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

### 步骤 0：先问一句前置——"这是超级成长股吗？买入逻辑是什么？"

- 完成标准：明确写出该标的的买入逻辑（为什么买、当初基于什么景气/逻辑），以及它是否符合超级成长股特征。
- 判停条件：若用户根本说不清买入逻辑，或标的明显不是超级成长股（业绩差、景气向下、纯炒概念），**跳到步骤 4**（这不是本 skill 的目标场景，转 `real-vs-fake-value-investing` / `super-growth-stock-criteria`）。

### 步骤 1：判停——"基本面是否出现向下拐点？"（这是止盈/止损的分水岭）

- 动作：调用 `prosperity-and-inflection` 的判断框架，用财报数据检查：行业增速是否下滑？公司业绩是否不及预期？核心成长逻辑是否被破坏？（拐点靠财报"清晰展现"，不靠猜。）
- 完成标准：给出明确的二分判断——"基本面已拐点" or "基本面未拐点（景气度不变）"。
- **判停分支**：
  - 若**基本面已拐点** → 跳到 **步骤 2b（止损/止盈路径：砍仓）**
  - 若**基本面未拐点** → 跳到 **步骤 2a（持盈路径：继续死拿）**

### 步骤 2a：持盈路径（基本面未拐点）——继续持有，不因价格卖

- 动作：
  - 明确告诉用户"不卖"。即便有30%-40%回撤、甚至腰斩，只要基本面没拐，回撤是噪音。
  - 提醒"不要逃顶"：顶部只有一个，逃顶千次只对一次；为躲回撤提前止盈会卖飞主升浪。
  - 提醒"不要赚点就跑"：以"不卖"的心态持有，目标是5-10倍而非20%。
- 完成标准：用户能复述"卖出的唯一依据是基本面拐点，不是价格涨跌"，并能说出当前基本面未拐点的依据。

### 步骤 2b：止损/止盈路径（基本面已拐点 或 逻辑看错）——立即砍仓

- 动作：
  - 明确告诉用户"砍仓，无论浮亏多少"。这是止盈（盈利侧拐点）还是止损（亏损侧拐点/看错），由当前持仓盈亏状态决定，**但动作一样：卖出**。
  - 区分两种触发：①逻辑看错（标的根本不该买，与价格无关）→ 砍；②基本面向下拐点（标的不再是超级成长股）→ 砍。
  - 严禁在此路径建议"摊平成本/越跌越补"——基本面恶化时补仓=加速亏损（致命恶习）。
- 完成标准：用户能区分自己属于"看错"还是"拐点"，并明确了砍仓动作而非补仓。

### 步骤 3：复盘——"对手方为什么在卖？"（卖出三思，对抗摊平冲动）

- 动作：当用户面对下跌想补仓时，反问"卖出的人为什么卖？"——把决策建立在对交易对手逻辑的推测上，而非"跌多了就便宜"。
- 完成标准：用户能说出卖出方的可能逻辑（基本面恶化/逻辑破坏），并据此决定是砍是拿，而非机械摊平。

### 步骤 4：转交相邻 skill（非本 skill 场景）

- 动作：若判停在步骤 0，或用户问题本质是"识别拐点/判断真假价投/怎么买"，明确告知用户应转用哪个相邻 skill。
- 完成标准：用户知道下一步该调哪个 skill。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯买入决策**：用户在问"该不该买/怎么买/分几仓"，用 `scale-in-and-risk-control`，不是本 skill。
- **识别拐点本身**：用户在问"这个行业的景气度变了吗/拐点到了吗"，用 `prosperity-and-inflection`。本 skill 依赖那个 skill 先给出拐点判断，自己不预测拐点。
- **技术面止损/移动止损/网格/做T**：本 skill 明确反对任何与价格/技术形态挂钩的卖出规则（达X%止盈、跌Y%止损、破位卖出）。作者把卖出唯一锚定在基本面拐点上，技术止盈止损会与"不逃顶、基本面拐点才卖"的根本原则冲突。
- **不是超级成长股的标的**：本套持盈止损纪律的前提是"选对了超级成长股"。对业绩差、景气向下、纯炒概念的标的套用"持盈不止盈/接受回撤"=死扛垃圾股，是毁灭性的。

### 作者在书中警告的失败模式（反场景）

- **ce06 为躲回撤而提前止盈（逃顶幻想）**：看到浮盈回撤就赶紧落袋为安，卖飞后面数倍主升浪，长期收益远低于死拿。顶部只有一个，逃顶千次只对一次。作者定调"卖飞比套牢更致命"。
- **ce09 拿不住盈利——赚点就跑**：盈利20%就惶惶不安落袋为安，把"小赚多次"误等同"稳健"，事实上卖飞主升浪的期望值损失远大于偶尔躲回撤的收益，无法实现财富跃迁。
- **ce10 舍不得止损——亏了死扛**：与"拿不住盈利"对称的人性偏误：盈利时急卖、亏损时死扛。认亏等于承认判断错误，故本能选择"不卖就不算亏"，叠加摊平成本幻想，最终小亏变大亏、深度套牢、失去翻身本金。
- **ce05 越亏越补/摊平成本（基本面恶化标的）**：把"摊平成本"误用于基本面已恶化的标的。"摊平成本"只在景气度不变的核心成长股上正确，在恶化标的上是加速亏损。补仓理由是"成本降到X就回本"=只看价格不看基本面。
- **p30 越亏越补是致命恶习**：作者铁律——"越亏越补、摊平成本，是散户的致命恶习"，必须先问"卖出的人为什么卖"，而非"跌多了就便宜"。

### 作者的盲点 / 时代局限（来自阶段 0 批判，B 段强标）

- **死拿在"买错时"是毁灭性的**：作者把"单票腰斩很常见"轻描淡写，淡化该策略在**熊市/震荡市或买错时**的毁灭性回撤。BOOK_OVERVIEW 批判明确指出："回调分仓买入 + 死拿"在买错时恰恰是加速亏损。本 skill 的持盈纪律**只在"选对了α"前提下成立**——这是它的不对称前提，不是普适真理。
- **单票腰斩常见 ≠ 可承受**：作者隐含假设读者能承受50%+回撤与长期浮亏，对绝大多数普通人不可承受。30%-40%回撤容忍框架对心理素质和资金属性有极高隐性门槛。
- **幸存者偏差 + 后视镜叙事**：作者列的每只10倍股都是事后赢家；2021年初同样符合"6条标准+创新高+景气"的部分新能源/CRO后来腰斩甚至退市。没有证据表明"死拿"的前瞻胜率高于市场。"卖飞比套牢致命"成立的前提是"你选对了α"——若选错，套牢才是致命的。
- **"卖飞比套牢致命"的对称性盲点**：作者只讲卖飞的损失，不讲在景气拐点后仍死扛（伪价投）的损失——后者在熊市/买错时同样致命。本 skill 的执行必须配合"基本面是否拐点"的诚实判断，否则持盈会异化为死扛。

### 容易混淆的邻近方法论

- **技术止盈止损（达X%卖/破位卖/移动止损）**：与作者体系根本冲突。作者锚定基本面拐点，反对任何价格/形态触发的卖出。用户若带着"设置止损线"的预期来，需明确告知本 skill 不提供这类规则。
- **网格/做T/高抛低吸**：作者明确反对"反复做T试图吃尽波动"——这与持盈不止盈、不逃顶直接冲突。
- **价值投资的"长期持有"**：长线持有是好公司的朋友、烂公司的敌人。本 skill 的"持盈"≠对任何标的都死拿，前提是标的仍是超级成长股（与 `real-vs-fake-value-investing` 的"伪价投"边界接壤）。
- **"敢全身价压上"≠重仓单吊**：持盈纪律与仓位纪律不同——本 skill 管卖不卖，仓位红线（不加杠杆/不单吊）由 `scale-in-and-risk-control` 管，两者不能混淆。
