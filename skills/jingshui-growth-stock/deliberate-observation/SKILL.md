# 刻意观察法（消费股生活信号捕捉）

## R — 原文 (Reading)

> "把'刻意观察'刻进脑子里，在日常工作、逛街、旅行、网购、刷视频的全过程中，主动寻找一个信号：什么东西是过去没有的，当下却突然爆火、快速普及。盯住这种爆火的新产品，找到它的上市公司。"
>
> — 静水2008，第四章第15节

---

## I — 方法论骨架 (Interpretation)

这是一种把日常生活变成选股信号源的方法，作者命名为"刻意观察法"，本质是彼得·林奇式选股在消费赛道的落地。

1. **建立扫描反射**：把"主动寻找'突然爆火'信号"刻进脑子，在逛街、网购、刷视频时下意识运转。
2. **锁定信号特征**：只认一种信号——"过去没有 + 当下突然爆火 + 快速普及"。渐进改良的不算，必须是新生的、爆发式扩散的。
3. **五新放大镜**：扫描新产品、新产业、新服务、新业态、新机遇（"新"字为根）。
4. **定位上市主体**：爆火产品 → 反查它背后的上市公司（很多是母公司，如好想来背后是万辰集团）。
5. **财报验证再介入**：观察只是线索，不是结论。必须用财报验证成长性（主营增速、供需、景气度）成立，再谈介入。
6. **主场优势**：消费是普通人最易感知、最接地气的赛道——你不需要内幕，你每天都在产线现场。

核心心智：你不是在"炒股"，而是在"把生活经验转成投资判断"。

## A1 — 书中的应用 (Past Application)

### 案例 1：好想来（万辰集团）— 零食量贩店遍地开花
- **问题**：如何在消费赛道用普通人视角发现 10 倍股？
- **方法论的使用**：作者观察到线下"好想来"零食量贩店快速扩张、门店遍地开花，这是典型的"过去没有、当下突然爆火"业态。定位其上市母公司——万辰集团。
- **结论**：把生活观察转成研究入口，启动基本面投研。
- **结果**：好想来（万辰集团）后续业绩与股价验证了成长观察法的有效性。

### 案例 2：泡泡玛特 — 盲盒火出圈
- **问题**：新消费现象能否转化为投资标的？
- **方法论的使用**：在生活中捕捉到"盲盒突然爆火"的新消费现象（五新中的"新业态/新产品"），定位到上市公司泡泡玛特，再用财报验证其成长性。
- **结论**：观察发现线索 → 财报验证 → 择机介入。
- **结果**：泡泡玛特后续走出超级成长股行情。

### 案例 3：科沃斯 — 短视频引爆扫地机器人
- **问题**：渠道驱动的爆火产品算不算信号？
- **方法论的使用**：作者在刷视频过程中捕捉到"扫地机器人"被短视频内容快速引爆、从无到有普及的信号，定位上市公司科沃斯。
- **结论**：网购/刷视频场景同样可成为观察现场——"突然爆火"的渠道（短视频）本身也是"新"。
- **结果**：科沃斯后续走出超级成长股行情，是成长观察法的典型成功案例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **街头/商场观察**：看到某品牌门店排长队、某新品类店铺突然遍地开花（如某奶茶、某零食店、某潮玩店），心里想"这玩意儿这么火，能不能买它股票"。
2. **网购/短视频场景**：刷视频/电商时发现某个新产品（扫地机器人、盲盒、新茶饮、新美妆）反复刷屏、快速渗透，想判断是不是机会。
3. **亲友/同事讨论**：身边人都在抢某款新品、讨论某个新消费品牌，用户察觉到"突然流行"的信号但不知如何下手。
4. **旅行/异地观察**：在另一座城市发现某个本地还没普及但当地火爆的新业态，想提前布局。
5. **选股方法咨询**：用户问"普通人怎么选消费股""我没有专业信息源怎么找牛股"，需要一套从生活切入的可落地方法。

### 语言信号 (用户的话里出现这些就应激活)

- "最近 XX 突然火起来了，能买吗" / "XX 怎么到处都是"
- "街上某奶茶排长队，是不是机会" / "XX 火出圈了"
- "怎么从生活中发现牛股" / "普通人怎么选消费股"
- "这个产品过去没见过，现在突然流行" / "viral / breakout / next big thing"
- "我看到 XX 在短视频里到处都是"

### 与相邻 skill 的区分（初稿，阶段 3 回填定稿）

- 与 `three-selection-methods` 的区别：three-selection-methods 是选股方法**总地图**（成长观察/财报/周期三法并列）；本 skill 是其中"成长观察法（林奇法）"在**消费赛道**的深化操作手册——把"怎么观察、观察什么信号、怎么从产品走到上市公司"具体化。
- 与 `financial-report-signals` 的区别：financial-report-signals 是从财报**逆向**筛牛股（关键词扫描、量价齐升、供不应求）；本 skill 是从**生活**正向发现线索。两者是上下游：观察发现线索后，用财报验证（A1 案例 2 明确"再通过财报验证成长性"）。
- 与 `industry-alpha-locking` 的区别：industry-alpha-locking 回答"这个行业里谁是 α"（已有行业焦点）；本 skill 回答"哪里有突然爆火的新东西值得深挖"（焦点未定，从生活信号出发）。爆火产品对应的可能是一只新 α，但需经 industry-alpha-locking 二次确认。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **确认信号特征 — 是不是"突然爆火 + 快速普及 + 过去没有"**
   - 完成标准：明确回答三个问题——①这个东西过去有没有？②当下是否在快速扩散（门店/销量/讨论度爆发）？③是不是可被普通消费者感知的"新"（产品/业态/服务/渠道）。
   - 判停条件：若只是渐进改良、或老品类的常规增长，则**否决**，告知用户这不是刻意观察法的目标信号，结束。

2. **定位上市主体**
   - 完成标准：找到爆火产品对应的**上市公司**（注意：品牌名常 ≠ 上市主体，如好想来 → 万辰集团）。列出公司名、股票代码、主营构成、该爆火产品在主营中的占比。
   - 判停条件：若查不到对应上市公司（如纯初创/未上市），告知用户当前无可投资标的，转入持续观察。

3. **财报验证成长性**
   - 完成标准：调出最近 2–4 期财报，验证——①主营增速是否 ≥40%（超级成长股硬标准）；②是否出现"供不应求/景气上行/超预期拓展/新品超预期/价格中枢上行"等关键词；③产业趋势是否向上。给出"成长性是否成立"的明确判断。
   - 判停条件：若财报不支撑（增速低、供需无矛盾、景气向下），明确告知"观察信号≠成长性，否决"，结束。

4. **确认可持续性，再谈介入**
   - 完成标准：判断爆火是**长期产业趋势**还是**短期流行**——是否有持续的新品/新应用场景拓展、是否处于供不应求的卖方市场。若可持续，移交 `industry-alpha-locking` / `scale-in-and-risk-control` 决定介入时机与仓位；若仅为短期流行，建议放弃。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **周期股拐点判断**：观察钢铁/化工/航运价格变化是周期法的事，不是消费观察法的目标——用 `industry-alpha-locking` + 周期法。
- **纯财报驱动选股**：若线索来自财报扫描而非生活观察，用 `financial-report-signals`，不要倒推一个"生活故事"硬套本 skill。
- **B 端/工业品/未触及消费者的赛道**：刻意观察法的主场是消费（"消费是普通人主场"）。光模块、PCB、算力这类 B 端产业链，普通人无法从生活中观察，应走财报法。
- **短期流行 vs 长期趋势未分辨时直接介入**：观察只产生线索，不产生结论。网红产品 ≠ 超级成长股。

### 作者在书中警告的失败模式

- **ce02（只盯买卖点忽视公司质地）**：本末倒置研究买卖点，忽视公司是不是超级成长股。刻意观察法只解决"线索从哪来"，不解决"质地够不够"——必须接财报验证，否则等于在垃圾股上找"完美买点"。
- **ce13（分散注意力追热点）**："什么热点都想蹭、什么小机会都想抓，注意力被切割得支离破碎。" 刻意观察法的反面就是无差别追每个网红产品。正确姿势是发现线索后**深挖一个**，而非同时追十个爆火现象。

### 作者的盲点 / 时代局限（来自阶段 0 批判）

- **爆火 ≠ 可持续**：作者列举的好想来/泡泡玛特/科沃斯都是**事后赢家**。同样"突然爆火"的网红品牌（部分新茶饮、潮玩、网红零食）后来衰退甚至退市。观察法有强烈的**幸存者偏差**——只记住了押中的案例。
- **消费观察有滞后性**：当你能在生活中感知到"遍地开花"时，往往已经是扩散中后期，股价可能已反映。作者未充分讨论信号早衰问题。
- **"消费是普通人主场"被绝对化**：作者把消费观察包装为"最易落地"，但消费赛道的爆发性 10 倍股并不每轮都有（19–20 之后消费主线已切换），普通人若只固守消费观察，可能在 AI/B 端行情中完全踏空（参见 c13"它涨你跌"）。
- **把观察法说成"只要坚持就能押中"**：识别+财报验证+拿住是三个独立高门槛，作者用连贯叙事掩盖了难度（BOOK_OVERVIEW 批判：幸存者偏差 + 后视镜叙事）。

### 容易混淆的邻近方法论

- 与 `three-selection-methods`：是整体 vs 局部关系（本 skill 是三法之一的深化），不要混用。
- 与 `financial-report-signals`：正向生活线索 vs 逆向财报筛选，方向相反，但**互补**——观察线索 → 财报验证是标准链路。
- 与 `industry-alpha-locking`：从生活出发找新 α 候选 vs 在已知景气行业里锁定核心 α。爆火产品可能是 α，但需经后者二次确认。
