# 散户七大通病自检清单

## R — 原文 (Reading)

> "1. 穷人思维：偏爱便宜垃圾股……2. 恐高症：不敢买新高的好公司……3. 拿不住盈利……4. 舍不得止损……5. 频繁交易……6. 喜欢预判……7. 分散注意力：沉迷小机会……"
>
> — 静水2008，第五章 第19节（散户七大通病集中列举）

---

## I — 方法论骨架 (Interpretation)

作者把散户亏钱的主因归纳成七条带机制的"通病"，每条都给出失败模式、心理机制、预警信号，可直接当诊断清单用：

1. **穷人思维**：把消费场景的"便宜=划算"心智迁移到股市，偏好低价低位股——但"便宜自有便宜的道理"，多是基本面恶化的结果。
2. **恐高症**：股价创新高的好公司不敢买，宁可去抄下跌弱势股——恐高其实是穷人思维的延伸，违背"强者恒强"的惯性。
3. **拿不住盈利**：盈利 20% 就落袋为安，与第四条"舍不得止损"对称，构成处置效应——卖飞主升浪的期望值损失远大于偶尔回撤收益。
4. **舍不得止损**：亏损时死扛补仓摊成本，把"没卖就不算亏"当自我安慰，最终小亏变大亏。
5. **频繁交易**：短线越短越趋近随机游走，叠加成本后期望为负，且掠夺研究时间，永远停在认知浅层。
6. **喜欢预判**：总想抄底猜拐点，而作者方法论核心是"只跟随不预判"，用创新高+回调分仓替代猜底。
7. **分散注意力**：每个热点都想蹭，资源被切碎，"败兵先战而后求胜"，等十倍主线到来时已无资金无精力无胆识。

这是一份**高密度反向赋能**清单：不是泛泛说"心态不好"，而是七条可逐条对照定位亏损主因的具体行为模式。

## A1 — 书中的应用 (Past Application)

### 案例 1：恐高症——恐高不敢买新高好公司（ce07 / ce08 系同源）

- **问题**：作者观察到散户普遍"宁愿买下跌趋势的弱势股，也不买上升趋势的强势股"，把"恐高"当理性，结果错过主升浪。
- **方法论的使用**：作者把"恐高"重新定义为穷人思维的延伸——新高恰恰是全员认可、无抛压、概率在你这边的上车信号；"便宜自有便宜的道理"，低位弱势股缺乏上涨核心逻辑。
- **结论**：散户的恐高不是谨慎而是认知错误，违背事物发展的惯性规律（强者恒强）。
- **结果**：作者据此给出口诀——只跟随不预判，创新高=趋势识别最简标准，回调分仓上车即可。

### 案例 2：拿不住盈利——赚 20% 就跑（ce09）

- **问题**：作者指出散户"赚 20% 就惶惶不安，赶紧落袋为安，结果卖飞了后面几倍的主升浪"。
- **方法论的使用**：用复利机制解释——复利难点在前期只考验不奖励、后期馈赠远超想象，但人性无法承受已到手利润的回撤；散户把"小赚多次"误等同"稳健"，事实上卖飞主升浪的期望值损失远大于偶尔的回撤收益。
- **结论**：卖飞比套牢更致命。盈利侧要宽容、接受 30–40% 正常回撤。
- **结果**：作者铁律——"持盈不止盈"，止盈唯一依据是基本面拐点而非价格涨幅。

### 案例 3：舍不得止损 + 频繁交易 + 喜欢预判（ce10 / ce11 / ce12）

- **问题**：散户"亏了死扛不断补仓"（ce10）、"每天追涨杀跌忙进忙出"（ce11）、"总觉得自己能预判行业反转抄大底"（ce12）。
- **方法论的使用**：三条合并诊断同一组人性偏误——亏损时认错等于自我威胁故死扛；短线越短越趋近赌博、久赌必输；拐点事前预判超出绝大多数人能力圈，作者方法论核心是"只跟随不预判"，用创新高+回调分仓替代猜底。
- **结论**：作者铁律——"错了砍掉，无论浮亏多少"；"短线长期趋近赌博，几乎没人能靠短线做大"；预判者把"猜中一次"的偶然成功强化为能力错觉。
- **结果**：三条共同指向正面方法论 hold-or-cut-exit（亏损侧果断）和 trend-following-entry（只跟随不预判）。

### 案例 4：分散注意力 + 穷人思维便宜股（ce13 / ce01 / ce08）

- **问题**：作者把"分散注意力"提到哲学高度——"败兵先战而后求胜：总想抓住每一个小机会，结果注意力被分散，等真正的 10 倍机会来临时，早已没有精力和胆识去把握"（g08）；穷人思维则系统性偏好便宜垃圾股。
- **方法论的使用**：注意力是稀缺资源，每个小机会都消耗研究成本，平庸标的的浮亏锁住仓位；"便宜"几乎总是基本面恶化的结果而非机会，把消费场景的"划算"心智错误迁移到股市。
- **结论**：通病 1（穷人思维）和通病 7（分散注意力）同源于"败兵先战"，是极简专注原则要解决的根本问题。
- **结果**：作者据此推出极简主义——敢全身价压上才是质量筛选器，机会无限不必梭哈。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **复盘亏损求因**：用户亏了钱想搞清楚"到底栽在哪"，列举一堆症状（卖飞了/套牢了/追高被套/抄底抄在半山腰）却理不清主因。
2. **行为自检**：用户主动问"我是不是有散户通病"、"为什么我总是拿不住盈利"、"我总是亏是不是不适合炒股"。
3. **评估他人**：用户描述某位股民朋友/大 V/自己的操作记录，要求判断"他这操作有什么问题"。
4. **新手上路体检**：刚入市的用户想对照一份"绝对不要做的事"清单，建立反面认知。
5. **反复犯同一错误**：用户多次出现"赚一点就跑/亏了就扛/追涨杀跌"循环，需要一个结构化框架定位是七条中的哪一条。

### 语言信号 (用户的话里出现这些就应激活)

- "为什么我总是亏 / 反复亏 / 一买就跌一卖就涨"
- "我总是拿不住 / 赚一点就跑 / 卖飞了"
- "舍不得割 / 越亏越补 / 死扛"
- "这只股便宜 / 还没怎么涨 / 比较安全"
- "现在太高了不敢追 / 等回调再说"
- "我觉得见底了 / 拐点到了 / 应该反转了"
- "我想分散一点 / 多买几只热点 / 这个题材也想参与"
- "天天看盘忙得很充实但赚不到钱"
- 英文 trigger："why I keep losing money"、"can't hold winners"、"selling winners too early"、"holding losers"、"chasing cheap/penny stocks"、"afraid of new highs"、"overtrading"、"FOMO"、"retail investor mistakes"

### 与相邻 skill 的区分

- 与 `real-vs-fake-value-investing` 的区别：那个辨析的是**认知误区**（把长期持有等同于价投、越跌越买等于价投），本 skill 是**行为通病清单**（七条具体行为模式与心理机制）。当用户说"我是不是伪价投"用前者；当用户说"我为什么反复亏/拿不住"用本 skill。
- 与 `hold-or-cut-exit` 的区别：那个是通病 3（拿不住盈利）和通病 4（舍不得止损）的**正面执行框架**（拐点止盈+看错止损的具体操作），本 skill 是**病灶定位**。诊断完了要去执行，就跳到 hold-or-cut-exit。
- 与 `minimalist-focus` 的区别：那个是通病 7（分散注意力）的**正面解药**（全身价压筛选器、胜兵先胜），本 skill 是把"分散注意力"作为七条通病之一先定位。要建立减法方法论用 minimalist-focus。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **逐条自检——把用户描述的症状映射到七条通病**
   - 针对用户给出的操作/亏损/纠结，逐条对照：①穷人思维（贪便宜买低位股？）②恐高症（创新高的好股不敢买，转去抄弱势股？）③拿不住盈利（盈利 20%就想跑？）④舍不得止损（浮亏死扛补仓摊成本？）⑤频繁交易（持仓平均<5 天/月交易次数远超研究次数？）⑥喜欢预判（买入理由是"我觉得见底了/反转了"？）⑦分散注意力（持仓跨 5 个以上不相关热点？每条新闻都想参与？）
   - 完成标准：每条给出"命中 / 未命中 / 信息不足"，命中的要附对应预警信号（warning_signs）。

2. **定位主因——挑出最致命的 1–2 条作为亏损主因**
   - 七条常同时出现，但通常有一两条是核心病灶。判断优先级：通病 4（不止损）和通病 7（分散注意力）往往是毁灭性的（前者失本金、后者失机会）；通病 1/2 同源（穷人思维延伸）；3/4 是处置效应的两面。
   - 完成标准：明确指出"主因是第 X 条 + 机制解释"，而非七条平铺。

3. **对应正面 skill——给出可执行的解药指向**
   - 主因 1/2（穷人思维/恐高）→ `trend-following-entry`（只跟随不预判，创新高上车）+ `industry-alpha-locking`（强者恒强）
   - 主因 3（拿不住盈利）→ `hold-or-cut-exit`（持盈不止盈，拐点才卖）
   - 主因 4（舍不得止损）→ `hold-or-cut-exit`（错了砍掉，无论浮亏多少）
   - 主因 5（频繁交易）→ `minimalist-focus`（极简专注，减少动作）
   - 主因 6（喜欢预判）→ `trend-following-entry`（只跟随不预判）+ `prosperity-and-inflection`（财报清晰展现拐点再确认）
   - 主因 7（分散注意力）→ `minimalist-focus`（全身价压筛选器，胜兵先胜）
   - 完成标准：每条命中的通病都指向至少一个正面 skill，并说明为什么这条通病恰好是该正面 skill 的反面。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **要诊断的是认知误区而非行为通病**：用户在纠结"长期持有到底算不算价投"、"越跌越买对不对"，这是 real-vs-fake-value-investing 的范畴（辨析伪价投），本 skill 只管七条具体行为。
- **要的是纪律执行动作而非自检**：用户已经知道拿不住、想要解决方案（怎么持盈、怎么止损），直接用 hold-or-cut-exit 给执行框架，不要停在"你这是通病 3"的诊断层。
- **要的是建立减法方法论**：用户想做减法、聚焦少数标的，直接用 minimalist-focus，不必绕一圈"你这是通病 7"。
- **纯信息查询**：用户只是问"什么是穷人思维/恐高症"的定义，直接回答术语即可，不必启动七条自检流程。

### 这份清单的局限（本 skill 本身就是反向清单，B 段写清单自身的局限）

- **七条未穷尽**：作者列的是其观察中的高频项，并非穷尽式分类。常见但未列入的还有：盲目抄作业/不独立研究、加杠杆、单吊梭哈、忽视仓位风控、追逐题材概念股等。诊断时若用户症状不在七条内，不要硬套，应直接承认"这不在作者列举的七条内"。
- **七条彼此重叠**：恐高症本质是穷人思维的延伸（都源于"贵的不安全"认知）；分散注意力（通病 7）与乱抓小机会（败兵先战，g08）同源；拿不住盈利（3）和舍不得止损（4）是处置效应的两面，并非真正独立的七条。定位主因时要识别重叠，避免把同源问题数成多个病。
- **机制描述是经验归纳非实证**：作者对每条通病的"mechanism"（如"短线越短越趋近随机游走胜率收敛到 50%"、"便宜总是基本面恶化的结果"）是其个人投资经验的归纳，**没有量化回测或统计胜率支撑**。把这些机制当诊断启发式可用，但不要当被证伪的科学定律引用。
- **后视镜叙事风险**：作者作为成功者列出的"通病"，是从其成功路径反推的；同样犯了这些通病但碰巧赚钱的人不会出现。引用 BOOK_OVERVIEW 批判——这是**典型的幸存者偏差 + 后视镜叙事**：作者列的每只"10 倍股"都是事后选出的赢家，没有证据表明"避免这七条"的前瞻胜率显著高于市场。
- **隐含高承受力假设**：通病 3"持盈不止盈、接受 30–40% 回撤"和通病 4"无论浮亏多少都砍掉"，隐含假设读者能承受 50%+ 回撤与长期浮亏，对绝大多数普通人不可承受。诊断时若用户资金体量小、风险承受低，不要把作者的铁律当普适处方强加。

### 作者在书中警告的失败模式（对应反例）

- ce01 / ce13（败兵先战 / 分散注意力）：把精力平摊到平庸机会，真正大机会来时无力把握。
- ce08（穷人思维）：系统性偏好便宜垃圾股，长期负收益。
- ce09（拿不住盈利）：反复赚小钱错过主升浪，复利被腰斩。
- ce10（舍不得止损）：死扛补仓，深度套牢、本金尽失。
- ce11（频繁交易）：被手续费、滑点、随机性吞噬本金，且掠夺研究时间。
- ce12（喜欢预判）：反复在下行通道接飞刀，错过已确立上升趋势的主升浪。

### 容易混淆的邻近方法论

- **vs real-vs-fake-value-investing**：那个辨析认知误区（伪价投=景气度向下还长期持有），本 skill 是行为通病（穷人思维/恐高/拿不住…）。两者常交织：散户可能是"伪价投"（认知错）+通病 4"舍不得止损"（行为错）双重叠加，诊断时要分清是认知层还是行为层的问题。
- **vs minimalist-focus**：那个是通病 7 的正面解药（减法方法论），本 skill 把"分散注意力"作为一条通病先定位。两者的风险：用户可能跳过自检直接要"极简方法"，但若其根本问题是通病 5 频繁交易而非通病 7 分散，minimalist-focus 不对症。
- **vs hold-or-cut-exit**：那个是通病 3/4 的正面执行框架，本 skill 是先诊断"是不是这两条"。风险：用户想要执行方案时本 skill 停在诊断层，应主动桥接到 hold-or-cut-exit。
