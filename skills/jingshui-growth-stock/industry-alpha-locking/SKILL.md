# 行业α锁定法（风暴之眼）

## R — 原文 (Reading)

> "每一轮产业行情中，最核心受益、业绩弹性最大、最被市场资金认可的标的，就是行业 α。它是风暴之眼。不需要复杂的分析，只需要反复问自己：当下时代最景气的行业是什么？行业中最核心的标的是谁？……买了行业内的杂毛公司，会被核心标的虹吸资金，出现'它涨你跌'。"
>
> — 静水2008，《极简成长股投资体系》第二章 第6节

---

## I — 方法论骨架 (Interpretation)

每轮产业行情里，资金不是均匀撒进整个板块，而是高度集中在一只或几只"风暴之眼"——业绩弹性最大、机构最认可、持续性最强的核心标的（作者称"行业 α"）。其余同板块公司是"杂毛"，会被 α 持续虹吸资金，出现"它涨你跌"。

锁定 α 的方法极简：两问法。第一问"当下时代最景气的行业是什么？"——把注意力从几千只股票压到一个行业；第二问"该行业最核心、最被资金认可的标的是谁？"——再压到一两只龙头。两问要"反复问"，刻成日常自问习惯。

判别 α 的可观测特征（不是凭感觉）：持续创新高（市场认可度）、业绩持续超预期（财报可验）、具备明显板块效应（带动整个细分板块上行）。三者齐备即为 α。

底层依据是"强者恒强"的惯性推理：基本面持续向好的公司趋势会延续，好公司股价永远不便宜；而基本面弱的杂毛会被资金虹吸、相对走弱。所以选股层面宁可买贵的好龙头，不买便宜的杂毛——这与"恐高""贪便宜"的散户本能相反。

---

## A1 — 书中的应用 (Past Application)

### 案例 1：三轮牛市 α 的跨周期识别（c10/c11/c12）

- **问题**：每轮行情里，同一个大板块（消费/新能源/AI）下面有几十只股票，怎么知道谁是这轮的"核心 α"？
- **方法论的使用**：作者用两问法 + 三特征（创新高 / 业绩超预期 / 板块效应）跨三轮周期识别 α。
  - 20–21 年消费牛市：茅台、汾酒、药明康德、片仔癀。
  - 21–22 年新能源牛市：宁德时代、天齐锂业、天赐材料、恩捷股份。
  - 24–26 年 AI 牛市：光模块、PCB 及设备、算力、半导体设备、存储。
- **结论**：这些标的的共同特征就是"持续创新高 + 业绩持续超预期 + 具备明显板块效应"——这正是 α 的可观测指纹。
- **结果**：三批 α 在各自牛市中持续创新高、业绩持续超预期，验证"锁定 α 即享超额收益"。作者把"在 AI 行情中赚到大钱"直接作为"是否合格景气价投"的判定标准。

### 案例 2：AI 行情中白酒被虹吸——"它涨你跌"反面（c13）

- **问题**：如果嫌核心 α 太贵，转去买"同板块里便宜/还没涨"的杂毛会怎样？
- **方法论的使用**：作者以"AI 行情中的白酒股"作反面教材——白酒不是 AI 主线，但投资者误以为"消费也是核心资产、白酒总该轮动"，结果资金从白酒持续虹吸进 AI 核心 α。
- **结论**：买杂毛不但享受不到 α 的超额收益，反而被 α 虹吸资金，出现"它涨你跌"。
- **结果**：AI 行情期间白酒股相对走弱，验证"非当轮景气主线的标的会被虹吸"。这反向印证了"必须锁定当轮 α、主动避开杂毛"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. **板块行情启动，要选具体标的时**：用户已经认定某个行业（如 AI / 新能源 / 创新药）是当下主线，但在板块内几十只股票里不知道买哪只，问"这轮 XX 行情我该买谁""谁是龙头"。
2. **持仓同板块弱势股不涨甚至跌时**：用户抱怨"主线大涨，我手里这只同板块的票不涨甚至跌"，问"该不该换""为什么它不涨"——典型的杂毛被虹吸。
3. **因嫌龙头贵、想找"还没涨的便宜替代"时**：用户说"XX 太贵了，有没有同板块还没涨的、便宜的"——正在踏入"买杂毛"陷阱。
4. **每轮行情复盘/下一轮布局时**：用户问"下一轮主线龙头怎么找""怎么判断谁是 α"——需要把两问法 + 三特征作为可重复流程交付。
5. **同板块多只候选难以取舍时**：用户列出 3–5 只同板块票问"挑哪只"——需要用"创新高 / 业绩超预期 / 板块效应"三特征做结构化筛选。

### 语言信号（用户的话里出现这些就应激活）

- "这轮 AI/新能源/XX 行情，买哪只？""谁是龙头 / 核心标的？"
- "同板块里挑哪只？""XX 板块的 α 是谁？"
- "我买的这只跟 XX 同板块，为什么它涨我跌？""为什么主线涨我的不涨？"
- "XX 太贵了，有没有同板块便宜/还没涨的替代？"
- "怎么判断谁是这轮的核心？""下一轮龙头怎么找？"
- 英文："which stock should I pick in this sector", "find the leader / core alpha of this rally", "why is my stock lagging while the sector surges", "which one to buy in this trend", "avoid the laggard in a hot sector"。

### 与相邻 skill 的区分

- 与 `super-growth-stock-criteria`（超级成长股六标准）的区别：六标准回答"这只股够不够格当超成长"——是**质地准入**；本 skill 回答"这轮行情里，在已合格的标的中选哪只龙头"——是**行情选龙**。前者是"够不够格"，后者是"这轮选谁"。逻辑上先过六标准筛资质，再用本 skill 在合格者中锁 α。
- 与 `trend-following-entry`（趋势跟随：创新高）的区别：趋势跟随解决"现在能不能买、何时买"——创新高是**买入时机信号**；本 skill 解决"选谁"——创新高在这里是**识别 α 的三特征之一**（市场认可度），不是买入动作。同一信号（新高）在两个 skill 里职能不同：本 skill 用它定位龙头，趋势跟随用它决定上车。
- 与 `prosperity-and-inflection`（景气度与拐点）的区别：景气度判断回答"这个行业整体向上还是向下、拐没拐"——是**体系总开关 / 前置判断**；本 skill 默认景气向上已确立，在其之上做"该行业里谁最核心"。先定景气（前者），再锁 α（本 skill）。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **第一问：锁定当下最景气行业（细分）**
   - 做什么：回答"当下时代最景气的行业/细分是什么？"——用财报关键词（供不应求 / 景气上行 / 量价齐升 / 超预期拓展）、行业增速、产业趋势来锁定一个**具体细分**（不是"科技"这种大类，而是"光模块""锂电池"这种细分配件环节）。
   - 完成标准：能一句话说出"当下最景气的细分是 XX，依据是 YY（财报/产业证据）"。
   - 判停条件：若无法用财报/产业证据锁定最景气细分 → 不要硬选 α，转 `prosperity-and-inflection` skill 先做景气判断。

2. **第二问：锁定该细分的核心 α**
   - 做什么：在该细分内，用**三特征**筛出核心 α：①股价持续创新高（市场认可度）；②业绩持续超预期（财报可验）；③具备明显板块效应（它涨带动整个细分上行）。
   - 完成标准：能说出 1–3 只候选 α，且每只都用三特征逐条验证过（缺任一特征要标注）。
   - 判停条件：若候选不满足"创新高 + 超预期 + 板块效应"中两条以上 → 它大概率是杂毛不是 α，回到候选池重选。

3. **主动避开杂毛 + 给出取舍理由**
   - 做什么：明确列出"同细分里容易被误买的杂毛"（通常特征：便宜、还没涨、基本面弱、不在机构重仓名单），并解释为什么不能买（会被 α 虹吸、"它涨你跌"）。对用户列出的多只候选，用三特征做结构化取舍，给出"买谁、不买谁、为什么"。
   - 完成标准：交付①本轮 α 候选清单（带三特征验证）②杂毛黑名单（带虹吸风险说明）③一句"宁可买贵的 α，不买便宜的杂毛"的取舍结论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **行业整体景气未确立 / 还在下行时**：本 skill 默认"当下最景气细分"已存在。若行业还在去库、增速下滑、无拐点，先转 `prosperity-and-inflection` 判断景气——在景气下行的行业里锁 α 是锁了个"伪 α"，会把"买龙头"做成"高位接盘"。
- **判断单只股"够不够格当超成长"时**：那是六标准的活（`super-growth-stock-criteria`）。本 skill 是在已合格标的里选龙头，不重复做资质审查。
- **判断"现在能不能买 / 何时上车"时**：那是趋势跟随 + 回调分仓的活（`trend-following-entry` / `scale-in-and-risk-control`）。本 skill 只管"选谁"，不管"何时买"。
- **风格切换期 / 周期底部**：风格切换期要挖"被错杀的低位优质成长"博戴维斯双击，周期底部要小仓位试错等拐点——这两个市场环境下"α"不是"创新高的最强龙头"，本 skill 的三特征会失灵，应转市场环境分类选股法。

### 作者在书中警告的失败模式

- **买杂毛被虹吸"它涨你跌"（ce19）**：在主线行情里买同行业的非核心标的（杂毛），不但享受不到超额收益，反而在 α 虹吸资金时同步甚至更大幅度下跌。买入理由若是"同板块 XX 太贵，这个便宜"，就是正在踩这个坑。
- **恐高不敢买核心 α（ce07）**：因 α"涨太多/创新高"而拒绝买入，转头去买下跌趋势的弱势股，完全违背强者恒强的惯性规律。恐高者把"绝对价格高"误等同"估值高/泡沫大"，错过最强趋势标的——作者直指这是"穷人思维"。
- **总想"找下一个风口"而忽视当下 α（ce22）**：放弃当下已明确的最强 α，去追逐尚未形成的"下一个 XX"，当下主升浪错过、未来也抓不住，两头落空。
- **对抗趋势 / 预判行情结束（ce23）**：在 α 主升浪中持续喊"泡沫/见顶"，把资金转向逆周期弱势标的，错过主升浪同时在弱势标的上亏损。

### 作者的盲点 / 时代局限（来自阶段 0 批判）

- **幸存者偏差（最关键）**：作者列出的 α（茅台/宁德/光模块）全是事后赢家。在 2021 年初同样符合"创新高 + 业绩超预期 + 景气"的标的（部分新能源、CRO）后来腰斩甚至退市。没有证据表明这套方法的前瞻胜率高于市场——三特征是"事后指纹"，事前用它们筛出的候选里仍有大量伪 α 会陨落。本 skill 的输出必须当作"高概率候选"而非"确定赢家"。
- **"24–26 AI"含前瞻预测**：作者把 AI 列为当轮 α 含未来时点预判，未必兑现；"强者恒强"被当公理，但历史上无数"强者"陨落（诺基亚、教培、部分白酒），作者以"惯性"一笔带过。
- **前提依赖特定流动性环境**："创新高 = 最强信号""强者恒强"依赖特定流动性环境与产业周期；若市场结构（注册制 / 退市 / 资金生态）变化可能失效。在结构性行情或缺主线震荡市，三特征会频繁误报。
- **隐含心理承受力假设**：α 在主升浪前常有 30–40% 回撤，作者把"单票腰斩很常见"轻描淡写，对绝大多数普通人不可承受。

### 容易混淆的邻近方法论

- **与"行业龙头"的区别**：行业龙头看市值地位、看谁是老大；行业 α 看本轮行情中的"业绩弹性 + 资金认可 + 持续性"。老大未必是这轮的 α（老牌龙头可能增速下滑、不在主线上），α 未必是历史龙头（新晋高弹性标的）。用"龙头"思维选股会锁定市值最大的那只，可能正是杂毛。
- **与"分散买整个板块 ETF"的区别**：买板块 ETF = 既买 α 也买一堆杂毛，会被杂毛拖累、稀释 α 的超额收益。本 skill 的核心主张是"主动避开杂毛"，与"分散持有全板块"在逻辑上对立。
- **与"低位捡便宜"的穷人思维（ce08）的区别**：本 skill 主张"宁可买贵的 α"，直接对抗"便宜=安全"的本能。若用户的核心信念是"便宜才安全"，本 skill 的输出会被系统性误用。
