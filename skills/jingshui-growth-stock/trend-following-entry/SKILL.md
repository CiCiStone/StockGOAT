# 趋势跟随（创新高·只跟随不预判·利弗莫尔巴菲特统一）

## R — 原文 (Reading)

> "趋势识别最好的方法只有一个：股价创历史新高……新高代表市场所有资金都认可，所有套牢盘都被解放，是最强的趋势信号。" "趋势投资的本质是跟随……你不需要比市场聪明，只要承认市场资金合力，站在概率的一边。" "只要景气度不变，利弗莫尔的趋势派买点与巴菲特的价值派买点都正确。"
>
> — 静水2008，第三章 第9节 / 第一章 第2节

---

## I — 方法论骨架 (Interpretation)

1. **最简趋势信号 = 股价创历史新高**：用单一可观测事实替代复杂择时。新高意味着全员资金认可、套牢盘被解放、上行无抛压——把"趋势是否确立"这个模糊问题压成一个客观判据。
2. **只跟随、不预判**：不猜顶、不抄底、不预测拐点；承认市场合力正确，等小回调上车。这是哲学层面的元选择，决定了后续所有动作的形态（创新高跟进、不逃顶、不抄底）。
3. **利弗莫尔与巴菲特在"景气度不变"下统一**：趋势派买在确立后、价值派买在错杀时，只要标的是景气度不变的超级成长股，两种买点都正确——殊途同归，无需在两派间选边。
4. **概率始终站在你这边**：在超级成长股上，回调买在最后一波是小概率事件；因此"等回调分批买 + 死拿"长期正期望，这恰恰是不逃顶、不择时的数学理由。
5. **前提硬约束**：创新高、强者恒强、概率优势全部依赖"景气度不变"且标的为真 α；景气一旦拐头，本 skill 整套逻辑立刻失效，转交止损/止盈体系。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: AI 产业链暴跌 → 两种买点统一（c03）
- **问题**: 同一只超级成长股，跌时该买还是涨时该买？利弗莫尔派和价值派看似冲突。
- **方法论的使用**: 作者用 AI 产业链受关税预期暴跌这一具体情境，演示"景气度不变"前提下两派买点的统一——暴跌时是巴菲特式买点（错杀），股价走出阴霾趋势向上时是利弗莫尔式买点（确立），两者都正确。
- **结论**: 买点分歧是表象，"基本面景气度不变 + 选对了超级成长股"才是共同前提；纠结该抄底还是该追高，是没看穿这层统一。
- **结果**: 作者断言"两者最终都能收获巨大收益，差别只在于涨幅多少"，验证了趋势跟随不必与价值投资对立。

### 案例 2: 买房选核心商圈 —— 克服恐高的类比（c14）
- **问题**: 散户看到创新高的好公司就恐高不敢买，偏爱低位弱势股，怎么破？
- **方法论的使用**: 作者用"买房选核心商圈"做类比：核心商圈房产因基本面强（地段不可复制）而长期高位，15 年里除最后一次外每次回调都是上车机会，最终涨幅远跑赢郊区低位房产。好公司股价高不是"贵"，是"基本面足够强"。
- **结论**: 恐高是把"绝对价格高"误等同于"估值高/泡沫大"的认知错误，本质是穷人思维；新高 + 回调 = 概率优势上车点，而非风险信号。
- **结果**: 该类比把抽象的"强者恒强"翻译成生活常识，作为克服恐高、敢在创新高处跟随的心理抓手。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **面对创新高的好公司犹豫**：标的基本面优秀且股价刚创历史新高或处于明显上升通道，用户因"涨太多/位置太高"不敢介入，转而考虑同板块"还没涨的"弱势股。
2. **主升浪中动摇想逃顶**：持仓已盈利且趋势完好，用户因"涨太多了总要回调"想提前止盈或反复做 T 高抛低吸。
3. **想抄底猜拐点**：用户在下行通道中反复接飞刀，买入理由是"我觉得拐点到了/见底了"，看不起"追高创新高"的买法。
4. **想找"下一个风口"**：当下主线已明确上涨，用户却忽视当下、把精力投到尚未形成的"下一个 XX"。
5. **择时 vs 选股的精力取舍**：用户在缠论/K 线/级别/背驰上耗时，与深度选股、读财报的精力产生冲突，问"该不该学技术分析找买点"。

### 语言信号 (用户的话里出现这些就应激活)

- "它已经翻倍了还敢追吗？" / "涨太多了，怕买在顶部"
- "创新高 = 创新高 (all-time high) / 突破 / 追高 (chasing) / 恐高 (fear of heights)"
- "是不是该逃顶了？" / "见顶 (top-calling) / 落袋为安"
- "我觉得拐点到了，可以抄底" / "抄底 (catching the bottom) / 见底 / 猜拐点 (inflection)"
- "这个板块涨过了，我去看下一个风口 (next big trend)"
- "缠论/级别/背驰/买卖点该怎么精修？" / "timing vs selection"

### 与相邻 skill 的区分（初稿，阶段 3 回填定稿）

- 与 `scale-in-and-risk-control` 的区别：本 skill 回答"何时/是否该买"的哲学层问题（创新高 = 趋势信号、只跟随不预判）；那个 skill 回答"买多少/怎么建仓"的执行层问题（回调分批分仓、两条红线、越跌越买的边界）。本 skill 给出"上车信号"，那个 skill 给出"上车动作"。
- 与 `prosperity-and-infaction` 的区别："景气度不变"是本 skill 的硬前提（决定创新高信号是否有效、概率是否真在你这边）；那个 skill 专门处理"如何观测景气度、如何识别拐点"。本 skill 默认调用前者的结论作为前置判断。
- 与 `industry-alpha-locking` 的区别：本 skill 的"创新高"必须建立在真 α 上才有意义——景气主线的核心标的创新高 = 趋势确立；杂毛创新高可能是诱多。那个 skill 负责"创新高的那个标的，到底是不是真 α"。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **前置校验：确认标的与景气度**
   - 该标的是否是当下景气主线的核心 α（不是杂毛、不是逆周期弱势股）？
   - 基本面景气度是否"不变"（财报无向下拐点、行业增速未下滑、核心成长逻辑未破坏）？
   - 完成标准：能一句话答出"最景气行业 + 核心标的是谁 + 景气度方向"。
   - 判停条件：若景气度已拐头向下，本 skill 直接停用，转交 `hold-or-cut-exit`（止损/止盈体系）。

2. **重框"恐高"为概率优势**
   - 把用户"涨太多/位置高"的顾虑，翻译成"创新高 = 全员认可 + 套牢盘解放 + 无抛压 = 最强趋势信号"。
   - 用买房选核心商圈类比（c14）说明：好东西从来不便宜，除最后一次外每次回调都是上车机会。
   - 完成标准：用户能复述"新高是信号不是风险，概率站在回调上车者一边"。

3. **给定动作：只跟随、回调分批上车**
   - 不追高一次性满仓，等回调分批介入（具体仓位动作交 `scale-in-and-risk-control`）。
   - 不预测顶、不抄没拐点的底、不找"下一个风口"而忽视当下主线。
   - 完成标准：用户接受"新高→等小回调→分批跟随"的路径，并放弃"猜顶/抄底/换风口"的预判冲动。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **景气度已出现向下拐点时**：创新高、强者恒强、概率优势全部失效；此时新高可能是末端冲顶，应转止盈/止损体系（交 `prosperity-and-inflection` + `hold-or-cut-exit`）。
- **标的是杂毛或基本面恶化股**：杂毛"创新高"可能是诱多或短炒，本 skill 仅适用于真 α；基本面恶化标的的"新高"无意义（交 `industry-alpha-locking` 判定）。
- **用户要的是技术点位精算/择时模型搭建**：本 skill 是哲学层"是否跟随、为何跟随"，不提供 K 线级别/背驰/买卖点计算（这种需求本身被作者否定，见 ce18）。
- **纯短线/题材炒作场景**：作者明令短线趋近赌博、题材不在体系内，本 skill 不为短线追高背书。

### 作者在书中警告的失败模式

- **ce07 恐高症**：不敢买创新高的好公司，偏爱低位垃圾股——本质是贪便宜的穷人思维，违背强者恒强的惯性规律。
- **ce12 喜欢预判**：总想抄底猜拐点，看不起追高创新高的买法；普通人猜底正确率微乎其微，反复在下行通道接飞刀。
- **ce22 找下一个风口**：忽视当下已明确的大趋势，去追逐尚未形成的未来风口，当下主升浪错过、未来也抓不住，两头落空（与 ce07 同根，源于对已涨标的的恐高）。
- **ce23 对抗趋势**：主升浪中持续预判"见顶/泡沫"，把资金转向逆周期弱势标的，用"逆向投资/独立思考"包装恐高与预判，是 ce07+ce12 的综合放大。

### 作者的盲点 / 时代局限（来自阶段 0 批判）

- **依赖特定流动性环境与产业周期**："股价创新高 = 最强信号""强者恒强"等前提依赖 A 股特定历史阶段（19–20 吃药喝酒、21–23 新能源、24–26 AI）；若市场结构（注册制/退市/资金生态）变化，新高信号可能失效。
- **历史上有无数"强者"陨落**：诺基亚、教培、部分白酒在创新高后基本面崩塌——作者把"强者恒强"当公理，对陨落情形以"惯性"一笔带过。需强调：本 skill 的"新高"必须严格绑定"景气度不变"前置，否则就是后视镜叙事。
- **幸存者偏差 + 后视镜叙事**：作者列出的创新高 10 倍股都是事后赢家；2021 年初同样符合"创新高 + 景气"的部分新能源、CRO 标的后来腰斩甚至退市。没有证据表明这套方法的前瞻胜率高于市场；"回调分仓 + 死拿"在买错时恰恰加速亏损。
- **隐含心理承受力假设**："接受 30–40% 正常回撤 + 死拿"预设用户能扛住长期浮亏与单票腰斩，对绝大多数普通人不可承受。

### 容易混淆的邻近方法论

- 与 **`scale-in-and-risk-control`（回调分仓 + 风控红线）**：本 skill 是"是否买/何时买"的哲学，那个是"买多少/怎么分批/红线在哪"的执行。用户说"该不该买"→本 skill；说"买多少、怎么分仓、能不能加杠杆"→那个。
- 与 **`prosperity-and-inflection`（景气度与拐点）**："景气度不变"是本 skill 的硬前提；那个 skill 提供前置判断。若用户问"这只股景气度拐了吗"，应先转那个 skill。
- 与 **`industry-alpha-locking`（行业 α 锁定）**：本 skill 的"创新高"只在真 α 上有效；那个 skill 判定"创新高的标的是不是真 α、会不会被杂毛虹吸"。
