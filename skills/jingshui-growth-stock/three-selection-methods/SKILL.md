# 三种选股方法地图

## R — 原文 (Reading)

> "成长股价值投资的选股方法只有三种，偏离这三种都找不到真正的超级成长股。1.成长观察法（彼得·林奇法）……2.财报选股法……3.周期选股法。"
>
> —— 静水2008，第二章 第5节

## I — 方法论骨架 (Interpretation)

作者把"如何发现超级成长股"穷举成三条互斥路径，没有第四条正道：

1. **成长观察法（彼得·林奇法）**：把日常生活变成信号源——主动寻找"过去没有、当下突然爆火快速普及"的新产品/新业态，定位其上市公司，再用财报验证成长性。门槛最低，普通消费者最容易触达，主战场是消费股。
2. **财报选股法**：财报季海量泛读财报（一年上千份），用关键词集合（供不应求/景气上行/超预期拓展/新品超预期/价格中枢上行）扫描定位潜在超级成长股。以量取胜、坚持为先，是作者认定的"普通人最便捷路径"。
3. **周期选股法**：对强周期行业（航运/有色/化工/存储等）在下行周期深入研究基本面，等财报"清晰展现"出供需拐点后布局。门槛最高，需要对产业周期有深度跟踪。

三法互斥且各自匹配不同可触达性：消费触达→成长观察；专业/时间触达→财报；产业深度触达→周期。三法都最终落到同一个出口——用超级成长股六条标准验证，并通过行业 α 锁定法收口到核心标的。

## A1 — 书中的应用 (Past Application)

### 案例 1: 好想来（万辰集团）/ 泡泡玛特 / 科沃斯 —— 成长观察法三连
- **问题**：普通人如何在消费赛道找到超级成长股？
- **方法论的使用**：作者用三个并列案例演示成长观察法的同一条流程——在生活中捕捉"突然爆火"信号（零食量贩店线下快速扩张、盲盒赛道、扫地机器人借短视频爆火），定位上市母公司（万辰集团/泡泡玛特/科沃斯），再走财报验证。
- **结论**：消费是普通人最容易感知、10倍股出现频率最高的赛道；成长观察法是消费股最自然的入口。
- **结果**：三者后续均走出超级成长股行情，作者把它们作为成长观察法的标准样板。

### 案例 2: AI 产业链"全产业链量价齐升" —— 财报选股法
- **问题**：24–26 年 AI 行情中，如何用财报法抓住主线？
- **方法论的使用**：财报季密集阅读财报，捕捉"量价齐升、供不应求、新品快速扩张、市场规模持续扩大"这一组关键词集中出现，识别超级成长股。作者明确把"在 AI 行情中赚到大钱"作为合格景气价投的判定标准。
- **结论**：财报选股法是验证"景气度"和捕捉主线的最直接工具；关键词集合命中即可定位候选池。
- **结果**：光模块/PCB/算力/半导体设备/存储等方向在 24–26 年持续创新高、业绩超预期，验证财报法对主线的捕捉力（含作者前瞻判断，存在后视镜风险，见 B 段）。

### 案例 3: 中远海控/天齐锂业（2021）与刀具/存储/油运（2025）—— 周期选股法
- **问题**：强周期行业如何在拐点附近布局？
- **方法论的使用**：对强周期行业（航运/锂/刀具/存储/油运）在下行周期深入研究基本面，等供需拐点被财报"清晰展现"后再介入；周期股盈利波动极大，拐点即最大机会。
- **结论**：周期法要求"事前深研 + 事后财报确认"，不靠猜底；财报是拐点的最终确认信号。
- **结果**：2021 年中远海控、天齐锂业成为周期大牛股；2025 年刀具/存储/油运被作者列为前瞻周期拐点机会（含前瞻性，未必兑现）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **零基础入场**：用户问"我是个普通上班族/学生/消费爱好者，怎么开始找 10 倍股"——按可触达性分流（消费触达→成长观察法）。
2. **方法路径迷茫**：用户已读了一些投资内容，但说不清自己该走哪条选股路径，或同时想"学技术分析+基本面+周期"——帮他收敛到三法之一。
3. **手握一只股不知怎么研究**：用户提到某只具体标的（如"XX 奶茶上市了能买吗""XX 周期股跌了很久能抄吗"），需要判断该用哪条路径展开投研。
4. **怀疑自己方法错位**：用户花大量时间在 K 线/买卖点上但收益平庸，问"我到底该研究什么"——重定向到三法之一。
5. **跨法切换**：用户已在用某法但遇到瓶颈（如消费赛道审美疲劳），想换一条路径——评估新路径的可触达性是否匹配。

### 与相邻 skill 的区分

- 与 `deliberate-observation`（刻意观察法）的区别：本 skill 是三法**总览+分流器**，负责告诉用户"你应该走成长观察法这条路径"；`deliberate-observation` 是成长观察法的**深化版**，负责在该路径内给出具体执行细节（五新扫描、从观察到投资的完整流程）。本 skill 触发后若判定走成长观察法，应转交/参考 `deliberate-observation`。
- 与 `financial-report-signals`（财报牛股信号）的区别：本 skill 是分流器，`financial-report-signals` 是财报法的深化版（关键词清单、以量取胜、财报季 12 小时）。本 skill 判定走财报法后转交它。
- 与 `prosperity-and-inflection`（景气度与拐点判断）的区别：本 skill 判定走周期法后，具体的"拐点如何观测、景气度如何判断"由 `prosperity-and-inflection` 承担。本 skill 只负责把用户导向周期法这条路径。
- 与 `super-growth-stock-criteria`（六条标准）的区别：六条标准是**三法的共同出口**（不管走哪条路，候选标的都要过六条标准验证），本 skill 是**入口分流**。两者是入口与出口的关系。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **评估用户的可触达性（accessibility）**
   - 问清/推断三条触达通道：①消费触达（日常是否高频接触消费品/线下业态/网购刷视频）②专业与时间触达（是否有时间财报季每天大量读财报、是否对数字/财务不排斥）③产业深度触达（是否对某个强周期行业有深度跟踪或从业背景）。
   - 完成标准：能明确指出用户在哪条通道上最有优势，或哪条通道几乎为零。

2. **按可触达性分流到三法之一**
   - 消费触达强 → 成长观察法（生活中找"突然爆火"信号 → 上市公司 → 财报验证）。
   - 专业/时间触达强 → 财报选股法（财报季海量泛读 + 关键词集合扫描）。
   - 产业深度触达强 → 周期选股法（下行周期深研 + 等财报确认拐点）。
   - 判停条件：若用户三条通道都弱（既不接触消费终端、也没时间读财报、也不懂任何周期行业），则跳到步骤 3 的"先补触达性"分支，建议从最易补的消费观察或财报泛读起步，不要硬塞三法。
   - 完成标准：给用户一个明确的方法选择 + 选择理由（基于其触达性）。

3. **给出该方法的入口动作 + 共同出口**
   - 入口动作（按所分方法二选一给）：
     - 成长观察法：列出过去 1–3 个月注意到的"突然爆火/快速普及"信号 3 条 → 每条定位一家上市公司 → 进入下一步验证。
     - 财报选股法：取最近一个财报季，用关键词集合（供不应求/景气上行/超预期拓展/新品超预期/价格中枢上行）扫描出 5–10 份命中财报 → 进入下一步验证。
     - 周期选股法：列出用户有深度跟踪的 1–2 个周期行业 → 标注其当前所处周期阶段（下行末期/底部/上行）→ 等财报确认拐点后再进入下一步。
   - 共同出口：无论哪条路径产出的候选标的，都要转交 `super-growth-stock-criteria` 用六条标准验证，再用 `industry-alpha-locking` 锁定行业 α，避免买到杂毛。
   - 完成标准：用户手里有 1 个明确方法 + 至少 1 个具体可执行的下一步动作（不是抽象建议）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **已锁定单只标的要判定"它是不是 10 倍股"**：这不是选股方法问题，是标的验证问题，应转交 `super-growth-stock-criteria`（六条标准）。
- **要判断某只持仓何时卖/该不该止损**：这是卖出框架问题，应转交 `hold-or-cut-exit`。
- **要做技术择时/找精确买卖点**：作者明确反对（见 ce02/ce18），本 skill 不会在择时方向上给任何支持。
- **用户的目标是短线快速致富**：作者断言短线路径走不通（ce17），本 skill 的三法均为中长线选股，不适用于短线目标。
- **纯信息查询**（"什么是成长股""A8 是什么意思"）：直接答术语即可，不需要走三法分流。

### 作者在书中警告的失败模式

- **ce02（研究买卖点而忽视公司质地）**：把时间投入到择时/买卖点精修上，却不去验证标的是不是超级成长股——择时再准也只赚到小钱，甚至买在垃圾股的"完美买点"上亏大钱。本 skill 的三法都强调"先选股"，反对本末倒置研究买卖点。
- **ce18（沉迷技术分析/缠论偷走选股注意力）**：技术分析理论自洽但属于择时范畴，沉迷者必然忽视选股。作者劝"尽早和技术分析告别"——择股与择时天然不相容，人的精力有限，沉迷择时必然放弃选股。本 skill 被激活时，若发现用户在纠缠 K 线/缠论/级别/背驰，应明确把用户拉回三法之一。
- **ce12/ce22（预判拐点/抄底/找下一个风口）**：周期法不是"猜底"，而是"等财报清晰展现拐点后确认"；成长观察法/财报法都强调"专注当下已爆火/已景气"的主线，而非预判下一个风口。

### 作者的盲点 / 时代局限（来自阶段 0 批判）

- **幸存者偏差 + 后视镜叙事**：作者列出的每只"10 倍股"（好想来/泡泡玛特/科沃斯/AI 链/中远海控/天齐）都是事后选出的赢家。在 2021 年初同样符合"突然爆火 + 量价齐升 + 景气"的标的（部分新能源、CRO、教培）后来腰斩甚至退市。没有证据表明这三法的前瞻胜率高于市场；三法本质是"事后能解释清楚"的框架，而非"事前能保证命中"的公式。
- **案例高度依赖特定历史阶段**（19–20 消费、21–23 新能源、24–26 AI）；其中 24–26 AI 与 2025 周期机会含前瞻预测，未必兑现。
- **隐含假设读者能承受 50%+ 回撤与长期浮亏**：成长观察法/财报法选出的标的在确认错误前会被鼓励"死拿"，对绝大多数普通人不可承受。
- **"三种之外皆非正道"是断言**：穷举式分类本身无法证伪，且排除了一些合理路径（如量化筛选、产业链映射、机构持仓跟随）。读者应把它当作"作者体系内的分类公理"，而非行业共识。

### 容易混淆的邻近方法论

- 与 `deliberate-observation` 的混淆：用户已经决定走成长观察法时，不需要再用本 skill 做分流，应直接进入 `deliberate-observation` 的执行细节。
- 与 `industry-alpha-locking` 的混淆：本 skill 回答"用什么方法找到候选"，`industry-alpha-locking` 回答"在候选池里锁定哪一只核心 α"。两者顺序上是先方法后锁定。
- 与 `super-growth-stock-criteria` 的混淆：六条标准是三法的共同出口验证器，不是第四种选股方法。不要把"用六条标准筛选全市场"当成第四法——作者是先用三法之一产生候选，再用六条标准验证。
