# 景气度与拐点判断（体系总开关）

## R — 原文 (Reading)

> "没有出现拐点的行业，即使处于历史低位，也看不到明确的希望……观测拐点的核心方法，是紧跟产业趋势：跟踪公司交流、调研纪要、行业研报与财报。拐点一旦到来，财报数据一定会清晰地展现出来。"另一处："只要标的基本面景气度不变，（利弗莫尔式与巴菲特式）两种买点都正确。"
>
> — 静水2008，第一章 第2节

---

## I — 方法论骨架 (Interpretion)

景气度是这套体系的总开关：一个标的是"上升中"还是"已拐头向下"，决定后面所有动作——
景气不变 → 回调分仓买、越跌越买、死拿、不止盈、不逃顶；
景气拐头向下 → 越跌越买立即失效、转为止盈/止损砍仓。
判断景气度方向唯一证据是**财报 + 产业跟踪**（公司交流、调研纪要、行业研报、新闻政策），
不看 K 线、不看情绪、不看绝对股价位置。
"拐点"是财报"清晰展现"后的**事后确认信号**，不是事前预测——作者明确反对猜底猜顶。
因此核心动作是"持续跟踪、等财报说话"，而非"判断行情会怎么走"。
当利弗莫尔派（创新高跟进）与巴菲特派（错杀抄底）看起来冲突时，
统一前提就是"景气度不变且为超级成长股"——满足此前提两种买点都正确。
周期底部连拐点都还没出现时，宁可小仓位试错等财报确认，绝不凭"跌多了"重仓抄底。

## A1 — 书中的应用 (Past Application)

### 案例 1: AI 产业链受关税预期暴跌时的巴菲特式买点（c03）

- **问题**：同一只超级成长股(AI 产业链)，暴跌时该买还是该等趋势走出来再买？两派(价值派抄底 vs 趋势派追新高)谁对？
- **方法论的使用**：作者不争论哪派买点更好，而是回到前置条件——**景气度是否变化**。AI 产业链受关税预期暴跌只是情绪/估值冲击，基本面景气度(算力需求、量价齐升)并未拐头，所以暴跌=巴菲特式买点；等股价走出阴霾趋势向上=利弗莫尔式买点。两种买点的前提都是"景气度不变 + 选对了超级成长股"。
- **结论**：景气度不变前提下，两种买点殊途同归，差别只在涨幅多少，不在对错。
- **结果**：作者称两者最终都能收获巨大收益——以"景气度"这个统一变量调和了对立学派。

### 案例 2: 周期底部试错布局——去库后期消费/走出集采医药/出海高增长制造遗珠（c16）

- **问题**：周期下行末期的行业（去库后期消费、集采冲击后的医药、出海高增长制造）跌了很久，能不能抄底？怎么抄？
- **方法论的使用**：作者不因"位置低/跌得多"就抄，而是给出一个两步动作：①在**财报中寻找率先复苏的标的**（即等拐点信号先在财报里"清晰展现"）；②**小仓位试错**，等行业景气拐点被财报确认后再加仓。核心是"不预测只确认"——拐点没被财报确认前只试错，确认后才重仓。
- **结论**：周期底部的买法是"财报先行确认 + 小仓位试错 + 拐点确认后加仓"，而非"跌多了就抄"。
- **结果**：作者将这三类方向列为周期底部试错的典型应用（拐点确认式布局的方法论示范）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **想抄底一个跌了很久的行业**：用户拿着一个"跌了 60%/历史低位"的标的问"能不能抄底/现在是不是底"。
2. **持仓大幅回撤，纠结该补仓还是该砍**：浮亏 30-40%，开始怀疑"景气度是不是变了"，需要判断是"景气不变的正常回撤"还是"基本面向下拐点"。
3. **盈利中要不要止盈 / 还能不能继续持有**：想知道"基本面拐没拐"——没拐就死拿，拐了就止盈。
4. **两种买点流派打架时想统一前提**：纠结该等创新高(趋势派)还是抄错杀下跌(价值派)。
5. **周期底部想做左侧布局**：处于下行末期的强周期行业，想试错又怕接飞刀。

### 语言信号 (用户的话里出现这些就应激活)

- "这个行业跌这么多了，是不是见底了 / can I bottom-fish / is the bottom in"
- "现在景气度还向上吗 / 还能继续持有吗 / 拐点到了吗"
- "越跌越买对不对 / 适合摊平成本吗 / can I average down"
- "长期持有算不算价值投资 / 我这是伪价投吗"
- "周期股什么时候布局 / 周期拐点怎么看 / cycle inflection"
- "卖飞了怎么办 / 该不该止盈逃顶 / take profit or hold"

### 与相邻 skill 的区分（初稿，阶段 3 回填定稿）

- 与 `hold-or-cut-exit` 的区别：那个 skill 教"识别拐点后**怎么卖**（止盈/止损动作）"；本 skill 教"**怎么判断拐点是否到来**"。本 skill 是它的前置输入——先确认拐点，再用那个 skill 执行卖出。
- 与 `three-selection-methods` 的区别：那个 skill 是"用哪条路径**发现**超级成长股"的地图（成长观察/财报/周期三选一）；本 skill 是发现之后、贯穿持有全程的"景气方向**持续监测**"。其中"周期选股法"以本 skill 的拐点判断为执行依据。
- 与 `trend-following-entry` 的区别：那个 skill 用"创新高"识别趋势**确立**并上车；本 skill 的"景气度不变"是创新高买点能成立的前提（景气拐头向下时新高无意义）。本 skill 偏方向监测，那个偏入场信号。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **先校验前提：标的必须是超级成长股或强周期股**
   - 完成标准：明确标的属于"景气可观测的成长股/周期股"而非纯概念/纯垃圾股；若不是，直接告知"本 skill 不适用，先过超级成长股六条标准"。
   - 判停条件：若标的纯炒概念/无业绩/主营增速<40%且非周期股 → 跳出本 skill，转 super-growth-stock-criteria。

2. **收集景气度证据（财报 + 产业跟踪）**
   - 用四类信息源核查当前景气方向：①最新季报/年报关键数据（营收增速、毛利率、订单、产能利用率、价格中枢）；②公司交流/调研纪要（管理层对需求/供给/价格的判断）；③行业研报（行业整体增速、供需格局）；④新闻/政策（宏观稳定、行业政策、产业事件）。
   - 财报侧用关键词集合扫描：供不应求/供给偏紧/需求旺盛/景气上行/超预期拓展/新品超预期/价格中枢上行 → 景气向上信号；行业增速下滑/业绩不及预期/订单取消/库存堆积/价格下行 → 向下拐点信号。
   - 完成标准：用这四类证据给出"当前景气方向"的明确判断（向上/持平/向下拐头），而非含糊结论。

3. **判断拐点是否被财报"清晰展现"**
   - 区分两种状态：①情绪/估值冲击导致的股价下跌（财报景气证据仍向上）→ 不是拐点，属"景气不变的正常回撤"；②财报本身出现向下信号（增速/订单/价格中枢转弱）→ 向下拐点确认。
   - 完成标准：明确回答"这是价格波动还是基本面拐点"，并标注证据来源。
   - 判停条件：若证据不足以"清晰展现"拐点（财报还没发/数据矛盾）→ 默认按"未确认拐点"处理，不下"已拐头"结论，也不鼓励用户事前猜。

4. **按景气方向给出动作建议（与相邻 skill 协同）**
   - 景气向上 + 价格回撤 → 回调分仓买入 / 越跌越买（限景气不变）/ 持盈不止盈（交 scale-in、hold-or-cut）。
   - 景气向上 + 周期底部未确认拐点 → 小仓位试错，等财报确认拐点后再加仓（不重仓抄底）。
   - 向下拐点已确认 → 立即转 hold-or-cut-exit：止盈或止损砍仓，越跌越买立即失效，禁止以"长期持有=价投"硬扛。
   - 完成标准：动作建议明确挂在"景气方向"这一前置判断上，不依赖股价位置或情绪。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **想预测顶/底、要一个事前拐点时**：本 skill 的方法论是"不预测、只确认"，只能等财报"清晰展现"后给出事后判断。要求"预判拐点/抄大底"的请求，本 skill 会主动拒绝并指向 ce12 的失败模式。
- **标的并非超级成长股/周期股时**：景气度框架只对成长股与强周期股有效；纯概念股、纯垃圾股、纯防御股不适用，应先过超级成长股六条标准。
- **只想问纯择时/K 线反转信号时**：本 skill 的证据是财报+产业跟踪，不是技术形态。要 K 线择时应转向趋势跟随/技术分析类 skill（但作者体系内不鼓励技术择时）。
- **财报尚未发布、产业证据空白时**：在"无法清晰展现"的状态下本 skill 不能下"已拐头"结论，应明确告诉用户"当前证据不足以确认拐点，默认按未确认处理"。

### 作者在书中警告的失败模式

- **ce03 抄没拐点的底**：仅因"跌得多/历史低位"就抄景气下行、无拐点信号的行业，资金长期被套、错过同期高景气主线，机会成本与浮亏双重损失。作者明确："没有出现拐点的行业盲目抄底就是违背客观规律。"低位不等于便宜——低位常是基本面恶化的合理反映。
- **ce12 喜欢预判猜拐点**：把策略建立在"预判拐点/抄大底"上，正确率极低，反复在下行通道中接飞刀，错过已确立上升趋势的主升浪。作者直言"普通人猜底的正确率微乎其微"，方法论核心是"只跟随不预判"。
- **c02 伪价投式抄底**：白酒行业去库周期中业绩持续下滑仍被不停抄底，美其名曰"长期持有"——把景气度下行的标的用价投名义硬扛，必然亏钱。

### 作者的盲点 / 时代局限（来自阶段 0 批判）

- **无量化回测，靠经验归纳**：全书几乎无统计胜率，"财报清晰展现拐点"是经验性表述，没有给出可量化的拐点判据（如连续几季度增速、订单下滑幅度阈值）。读者在实操中"清晰展现"的阈值难以统一，存在主观裁量空间。
- **财报"清晰展现"有滞后性**：财报是季频披露，等"清晰展现"出向下拐点时，股价往往已经从高点回撤 20-30% 甚至更多。作者声称"不逃顶"靠拐点止盈——但在滞后确认下，止盈价位可能显著低于阶段高点，对回撤承受力是隐性考验。
- **景气度判断依赖信息优势与产业跟踪能力**：公司交流、调研纪要、行业研报并非普通人都能平等获取；作者作为有投研能力者其证据链质量高于普通散户，"紧跟产业趋势"对很多人是高门槛动作。
- **"景气度不变"是事后判定，事中难分辨**：在持仓回撤 30-40% 时，"这是正常波动还是景气拐头"在财报未发前无法确证；作者将其简化为"基本面没拐就坚定持有"，但用户很可能在证据不足时误判为"景气不变"而死扛，最终兑现为 ce10（舍不得止损）。
- **A 股 + 特定历史阶段假设**：案例高度依赖 19-26 年特定产业周期，"财报清晰展现"在退市常态化、注册制后的市场结构下未必同等有效。

### 容易混淆的邻近方法论

- 与 `hold-or-cut-exit`：拐点**判断**（本 skill）vs 拐点后的**卖出执行**（那个 skill）。混淆会导致本 skill 越界去教"怎么砍仓"，丧失前置判断的纯粹性。
- 与 `real-vs-fake-value-investing`：那个 skill 用"景气度方向"判定是否伪价投；本 skill 教"景气度方向怎么测出来"。两者协同：本 skill 是那个 skill 的判据提供者。
- 与 `trend-following-entry`：创新高是趋势信号，但只在"景气度不变"下成立；混淆会把景气已拐头的"创新高诱多"也当成买点。
