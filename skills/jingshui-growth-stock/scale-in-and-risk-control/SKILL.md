# 回调分仓买入与仓位风控两条红线

## R — 原文 (Reading)

> "找到核心α后，不要追高满仓，等待回调时分批分仓介入……越跌越买只适用于景气度不变的核心成长股，绝不能用在基本面恶化的标的上。"
> "绝对不要加杠杆……绝对不要单吊梭哈：没有人能百发百中，单吊一只标的，一次看错就可能重伤。分仓的收益并不比重仓差，但风险会大幅降低。"
>
> — 静水2008, 第三章 第9节 / 第12节

---

## I — 方法论骨架 (Interpretation)

这是"已经选好标的，怎么把钱放进去"的执行方法，回答三个问题：什么节奏买、放多重、绝对不能碰什么。

1. **节奏**：不追高一次性满仓，等回调时分批介入；目的是在不确定性中摊匀成本、提升胜率、降波动。
2. **仓位**：分仓持有，不重仓梭哈。理由不是分仓收益更高，而是"收益不比重仓差、但风险大降、心态更稳、更拿得住牛股"——分仓不损收益却同时降风险与心态损耗，是占优结构。
3. **两条绝对红线（先于一切收益考量）**：永不加杠杆、永不单吊梭哈。这是"无论如何不能破"的生存底线，不是建议。
4. **越跌越买有硬前提**：只在"景气度不变的核心成长股"上成立；基本面一旦恶化，越跌越买就是加速亏损。

整个方法的核心张力在于：选股阶段用"敢不敢全身价压上"做严苛质量过滤（筛掉垃圾），执行阶段严令分仓（防单次看错致命）——筛选器是质量门槛，不是仓位指令。

## A1 — 书中的应用 (Past Application)

### 案例 1: 回调都是上车机会（买房选核心商圈类比，对应 c14）
- **问题**: 好公司股价已涨到高位，回调时该不该买？怎么买？
- **方法论的使用**: 作者用"买房选核心商圈"类比——15年里除最后一次，每次回调都是上车机会。锁定核心α后不追高满仓，而是等回调分批分仓介入，越跌越买（前提：景气度不变）。
- **结论**: 核心资产因基本面强而高位，回调即机会；分批介入而非一次性梭哈。
- **结果**: 核心商圈房产15年涨幅远跑赢郊区，类比验证"回调分批上高位好公司胜过一次性梭哈低位烂公司"。

### 案例 2: AI产业链受关税预期暴跌时的巴菲特式买点（对应 c03）
- **问题**: 标的受外部冲击暴跌，此时是补仓机会还是止损信号？
- **方法论的使用**: 作者判断"景气度不变"——AI产业链景气度未变，暴跌是巴菲特式买点（错杀买入）。在景气不变前提下，回调分仓买入与越跌越买都成立；同一标的趋势确立后又是利弗莫尔式买点。
- **结论**: 两种买点都正确，前提都是"选对了超级成长股且景气度不变"。差别只在涨幅多少。
- **结果**: 作者称两者最终都能收获巨大收益，验证"景气度不变"是回调分仓成立的前置开关。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **已锁定一只标的，准备下单，纠结买多少**：一次性满仓还是分批？仓位占比多少？
2. **持有的标的出现回调，犹豫要不要补仓**：越跌越买合适吗？补到什么时候停？
3. **极其看好某只标的，想把全部资金甚至加杠杆压上去**：能否单吊梭哈/上融资？
4. **被一只股票套牢，想"摊平成本"补仓**：补仓是聪明的回调分仓，还是越亏越补的恶习？
5. **新建仓位时规划资金结构**：单票上限、分几批、回调多少加一档。

### 语言信号 (用户的话里出现这些就应激活)

- "看好这只股，怎么建仓 / 分几批 / 仓位多重要"
- "回调了要不要补 / 越跌越买行不行"
- "这只我看得最准，能不能梭哈 / 全压 / 重仓"
- "要不要加杠杆 / 上融资 / 配资"
- "被套了，补仓摊平成本对吗"
- "scale in / average down / position sizing / how much to allocate / all-in on this / use leverage here"

### 与相邻 skill 的区分（初稿，阶段 3 定稿）

- 与 `trend-following-entry` 的区别: 那个解决"**何时买**"（创新高=趋势信号、只跟随不预判）；本 skill 解决"**买多少/怎么分布仓位/仓位红线**"。它判断入场时机，我执行入场动作与仓位结构。
- 与 `minimalist-focus` 的区别: 那个的"敢全身价压上"是**质量筛选器**（用极端押注意愿过滤掉垃圾标的），不是仓位指令；本 skill 在通过筛选后执行分仓。两者职能不同，不可混为一谈（误读"全身价压上"为重仓单吊是常见陷阱，见 B 段）。
- 与 `hold-or-cut-exit` 的区别: 那个解决"**买入后持有还是卖出**"（基本面拐点止盈/看错止损）；本 skill 只管"怎么把钱放进去"，买入后即移交给它。
- 与 `prosperity-and-inflection` 的区别: 那个是体系总开关，判断"景气度是否变化"；本 skill 把它的判断作为**前置判停条件**——景气度一旦拐头，回调分仓立即失效。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **前置判停：先确认标的景气度是否变化（最关键，不可跳过）**
   - 用最新财报/产业跟踪判断：行业增速是否下滑、公司业绩是否不及预期、核心成长逻辑是否被破坏。
   - 完成标准: 能用一句话回答"景气度是否不变"，并附财报/产业依据。
   - 判停条件: 若景气度已出现向下拐点或逻辑看错 → **立即停止本 skill**，不执行任何回调分仓/越跌越买；转 `hold-or-cut-exit` 处理（看错止损）。这是"越跌越买"的生死边界。

2. **规划仓位结构（落实两条红线）**
   - 单一标的仓位设上限（建议单票不超过可投资金的某个比例，分仓持有 3–5 只以上），永不单吊梭哈。
   - 任何情况下不得使用杠杆/融资/配资——这条无例外，先于一切收益考量。
   - 完成标准: 明确单票仓位上限、总持仓标的数、并显式确认"无杠杆"。

3. **执行回调分批介入**
   - 不追高一次性满仓；等回调时分批分仓买入（如分 2–3 档，回调到预设位置加一档）。
   - 越跌越买仅在"景气度不变"前提下进行（步骤 1 已确认）。
   - 完成标准: 给出分批档位（触发价位/比例）与单批仓位，全部受步骤 2 红线约束。
   - 判停条件: 若标的在补仓过程中基本面出现恶化信号（业绩/景气拐点）→ 立即停止加仓，转止损流程。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **基本面已恶化的标的上做回调分仓/越跌越买**：景气度向下时，"回调"不是机会而是价值毁灭，越跌越买 = 加速亏损（ce05/ce15）。此时唯一动作是止损而非补仓。
- **想用"敢全身价压上"为重仓单吊辩护时**：那是质量筛选器，不是仓位指令。把筛选器偷换成仓位指令会触发 ce28。
- **以"摊平成本"为理由在套牢标的上无脑补仓**：要先问"卖出的人为什么卖"，而不是"跌多了就便宜"。
- **还没选好标的时**：本 skill 的前提是已锁定景气度不变的核心α；标的未定谈不上仓位结构，去选股类 skill。
- **买入后该持有还是卖出的决策**：移交给 `hold-or-cut-exit`。

### 作者在书中警告的失败模式

- **ce24 加杠杆（哪怕方向看对也可能爆仓）**：杠杆把"可承受的暂时浮亏"变成"不可承受的永久清算"。超级成长股主升浪前常有 30–40% 回撤，杠杆者往往倒在这一段——方向对 ≠ 过程中不被清算。这是路径依赖风险。
- **ce25 单吊梭哈（一次看错即重伤）**：把全部仓位压单只，一次黑天鹅（造假/政策/个股黑天鹅）即终结投资生涯。任何选股方法都有失败概率，单吊把高胜率策略变成路径依赖赌博。
- **ce28 误读"全身价压上"为重仓单吊**：作者体系内有刻意张力——选股用"全身价压上"严苛过滤（防买垃圾），执行用"绝不单吊"分仓（防单次看错致命）。读者剥离上下文只取前半句，把质量判断偷换成仓位指令。
- **ce05/ce15 基本面恶化时越跌越买 = 加速亏损**：把巴菲特"便宜时买优秀公司"抽掉上下文滥用，前提"优秀公司"被偷换成"垃圾公司"。作者反复强调：越跌越买只适用于基本面不变的超级成长股。

### 作者的盲点 / 时代局限

- **单票腰斩被轻描淡写**：作者承认"单票腰斩很常见"，却把这种回撤当噪音淡化为"正常波动"，**淡化了该策略在熊市/震荡市或买错时的毁灭性回撤**。隐含假设读者能承受 50%+ 回撤与长期浮亏，对绝大多数普通人不可承受。
- **"分仓降风险不损收益"未经统计验证**：这是经验归纳而非回测结论。分仓在所选标的彼此独立时降风险，但在系统性熊市（所有成长股同步杀跌）或选股系统性偏差时，分仓并不能提供预期中的保护。
- **"两条红线"无法覆盖所有尾部风险**：不加杠杆、不单吊能避免爆仓与单次重伤，但无法防止"分仓持有的多只标的同属一个景气主线、主线整体崩塌"的系统性回撤（如教培、部分新能源）。
- **A 股 + 特定流动性环境局限**："回调分批买长期正期望""概率站在你这边"依赖 A 股高波动与产业周期红利，市场结构变化（注册制/退市常态化/资金生态）可能削弱该前提。
- **幸存者偏差**：作者只讲"做到了"的路径，不讲"同样回调分仓但买错或赶上熊市"的多数人。把需要极高信息优势、心理承受力与运气的方法包装成"普通人也能做到"，可能误导重仓高风险成长股。

### 容易混淆的邻近方法论

- **"回调分仓"≠"无脑定投"**：定投是时间驱动的机械建仓；回调分仓是价格驱动的择时分批，且仅限景气不变的超级成长股。
- **"越跌越买"≠"摊平成本"**：前者前提是景气度不变、标的是核心α；后者往往是在基本面恶化的标的上为逃避认亏而补仓。一字之差，盈亏方向相反。
- **"敢全身价压上"（筛选器）≠"重仓单吊"（仓位）**：见 ce28，是最高频的误读。
- **"分仓"≠"分散投资组合"**：作者的分仓是 3–5 只超级成长股层面降单票风险，仍是高集中度，与指数化分散有本质区别。
