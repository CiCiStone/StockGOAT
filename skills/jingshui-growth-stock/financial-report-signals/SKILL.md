# 财报牛股信号与海量泛读

## R — 原文 (Reading)

> "读财报是普通人挖掘 10 倍股最便捷、最高效的途径，没有之一……核心就是八个字：以量取胜，坚持为先……财报季重点关注这些关键词，一旦集中出现，就是潜在的超级成长股：产品供不应求、供给偏紧、需求旺盛；行业高景气度上行；市场超预期拓展；新品上市持续超预期；产品价格中枢持续上涨。"
>
> —— 静水2008，第四章 第13节

## I — 方法论骨架 (Interpretation)

作者把"读财报"从一项专业财务工程，改造成普通人可上手的检索式选股动作，核心有三层：

1. **信号层——关键词集合扫描**：把"这家公司是不是处于卖方市场、景气是否上行"这类定性判断，压缩成一组可命中的财报关键词（供不应求/供给偏紧/景气上行/超预期拓展/新品超预期/价格中枢上行）。集中出现 = 潜在超级成长股，不集中出现就跳过。本质是把判断转成检索。
2. **路径层——海量泛读以量取胜**：不深挖一家，而是财报季每天大量读（目标一年上千份），靠数量堆积形成对"景气度"的直觉。坚持一两年后阅读速度越来越快，能瞬间抓住核心矛盾。强调"先动手再学理论"——脱离实践的理论学习回报递减。
3. **目标层——只找当季新出现的超级成长股**：财报季每天 12 小时的唯一目标，是定位"当季最新出现的"景气拐点标的，不是给已有持仓做财务体检。

这套方法反"先看完教材再开始""深度研究一家公司"的常识——它要求你以检索者的身份先动手，量变引发质变。

## A1 — 书中的应用 (Past Application)

### 案例 1: AI 产业链"全产业链量价齐升"（c07）

- **问题**：24–26 年 AI 行情爆发期，普通人如何用财报法抓住这轮主线？
- **方法论的使用**：作者在财报季密集阅读产业链上中下游公司的财报，捕捉"量价齐升、供不应求、新品快速扩张、市场规模持续扩大"这一组关键词集中出现——光模块、PCB、算力、半导体设备、存储等方向同时命中，全产业链量价齐升的态势清晰可读。作者据此把"在 AI 行情中赚到大钱"直接定为合格景气价投的判定标准。
- **结论**：关键词集合集中命中即可定位候选池；财报选股法是验证"景气度"和捕捉主线的最直接工具，不用做财务建模也能上手。
- **结果**：上述方向在 24–26 年持续创新高、业绩持续超预期，验证关键词扫描对主线的捕捉力（含作者前瞻判断，存在后视镜与幸存者偏差风险，见 B 段）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **想用财报选股但不知怎么读**：用户问"财报那么长怎么看""有没有快速读财报的方法""财报季我该做什么"——给他关键词扫描 + 海量泛读的路径，而不是塞一本会计教材。
2. **拿到一份新财报要快速判断**：用户贴来 / 提到一份刚发的财报，问"这份财报说明什么""值不值得跟""是不是好信号"——用 5 组关键词做命中判断。
3. **卡在"先学理论再动手"**：用户反复说"等我学完财务分析/看完某本书再开始读财报"，多年仍停留在入门——破除准备瘫痪，推动先动手。
4. **财报季焦虑不知怎么投入**：用户问"财报季那么多财报怎么看得过来""一天该花多少时间"——给"雷打不动 12 小时海量泛读"的执行节奏。
5. **怀疑某只是不是"景气拐点"**：用户问"这只是不是要起飞了""财报这么好为什么"——用关键词集合反向验证景气度方向，而非看一两张报表。

### 语言信号 (用户的话里出现这些就应激活)

- "财报怎么读 / 财报选股怎么做 / 财报季做什么 / 财报季怎么投入"
- "这份财报说明什么 / 值不值得跟 / 是不是好财报"
- "供不应求 / 量价齐升 / 价格中枢上行 / 超预期 / 景气上行"（财报关键词本身）
- "以量取胜 / 海量泛读 / 一年读多少份财报"
- "等我学完 XX 再开始读财报"（准备瘫痪信号，反向触发）
- 英文："how to read financial reports / earnings-based stock picking / keyword scan / earnings season screening / what does this earnings report mean"

### 与相邻 skill 的区分

- 与 `three-selection-methods`（三种选股方法）的区别：那是**入口分流器**（回答"我该走哪条选股路径"），本 skill 是财报选股法这条路径的**深化执行**（关键词清单、以量取胜、财报季节奏）。它把用户分流到财报法后，转交本 skill。
- 与 `deliberate-observation`（刻意观察法）的区别：那是**生活信号 → 上市公司 → 财报验证**的消费股路径，信号源是线下/生活；本 skill 信号源是**财报文本本身**，是海量泛读的检索路径。两者互补：生活发现候选，财报扫描确认景气。
- 与 `industry-alpha-locking`（行业 α 锁定法）的区别：本 skill 回答"这份财报 / 这只股有没有景气信号"，`industry-alpha-locking` 回答"在同板块候选里锁定哪只核心 α"。财报信号是 α 锁定的前置素材。
- 与 `super-growth-stock-criteria`（六条标准）的区别：本 skill 是**发现候选的入口**（关键词命中 → 候选池），六条标准是**验证出口**（候选是否够格当 10 倍股）。先扫描发现，再用六条标准验证。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **判定用户处于路径哪一阶段**
   - 是"还没开始 / 准备瘫痪"（阶段 0）→ 跳到步骤 2 给入口动作。
   - 是"已有一份财报要判断"（阶段 1）→ 跳到步骤 3 做关键词命中扫描。
   - 是"已在财报季要规划投入"（阶段 2）→ 跳到步骤 4 给海量泛读节奏。
   - 完成标准：明确指出用户处于哪个阶段，避免给错阶段的建议。

2. **破除准备瘫痪，给"先动手"入口动作**
   - 直接拒绝推荐"先看什么财务教材"，定调八字："以量取胜，坚持为先"。
   - 给最小起步动作：取最近一个财报季任意一份已发财报，从头到尾通读一遍，不强求看懂每个数字，只找"有没有 5 组关键词的影子"。
   - 完成标准：用户拿到一个"今天就能做"的具体动作，且明确知道不需要先学理论。

3. **对用户给出的财报做关键词命中扫描**
   - 用以下 5 组关键词集合逐组判断是否命中（命中即标注并给原文片段）：
     ① 供不应求 / 供给偏紧 / 需求旺盛 / 下游排队 / 接受高溢价（卖方市场信号，g09）
     ② 行业高景气度上行 / 景气向上 / 行业拐点
     ③ 市场超预期拓展 / 新客户 / 新市场 / 市场规模持续扩大
     ④ 新品上市持续超预期 / 新品快速放量 / 新品贡献收入
     ⑤ 产品价格中枢持续上涨 / 提价 / 涨价
   - **关键词命中判断标准**：①命中的组数 ≥3 组，且至少有 1 组在原文中有明确表述（非泛化推测），判为"集中出现 → 潜在超级成长股，值得深究"；命中 ≤2 组判为"信号不足，跳过"；仅命中 1 组但表述极其强烈（如"严重供不应求+满产+下游排队"），单列提示但不作为强信号。
   - 判停条件：若财报里同时出现明显负面信号（产能利用率下滑 / 价格中枢下行 / 需求萎缩 / 库存大幅堆积 / 应收激增），即使正面关键词命中，也要在结论里标红"存在对冲信号，需进一步核验"，不能只报喜。
   - 完成标准：给出明确的命中组数 + 命中片段 + "是否值得跟"的结论。

4. **给财报季海量泛读节奏（仅当用户在阶段 2）**
   - 告知节奏：财报季每天 12 小时以上读财报，目标一年上千份，只找"当季最新出现的"超级成长股。
   - 强调量变引发质变：坚持一两年后能瞬间抓住核心矛盾，专业度会超过大多数行业研究员。
   - 共同出口：命中的候选标的转交 `super-growth-stock-criteria` 用六条标准验证，再用 `industry-alpha-locking` 锁定核心 α，避免读到信号却买到杂毛。
   - 完成标准：用户拿到一份财报季投入计划 + 候选标的验证出口。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用户要做严谨财务建模 / 三张报表深度分析**：作者明确反对（g18），他做的不是会计分析，关键词扫描替代不了应收/商誉/现金流粉饰的识别。需要真财务分析时应找专业工具，不用本 skill。
- **已锁定单只标的要验证"它是不是 10 倍股"**：这是标的验证问题，转交 `super-growth-stock-criteria`（六条标准）。本 skill 只负责"发现"不负责"验证够格"。
- **要判断某只持仓何时买 / 何时卖**：转交 `trend-following-entry`（创新高跟随）和 `hold-or-cut-exit`（拐点止盈 / 看错止损）。财报信号是选股层，不是交易层。
- **用户是消费赛道爱好者、信号来自生活而非财报文本**：应走 `deliberate-observation`（刻意观察法），本 skill 不是其入口。
- **不知自己该走哪条选股路径**：先走 `three-selection-methods` 做分流，本 skill 是分流到"财报法"之后的深化。

### 作者在书中警告的失败模式

- **ce26（准备瘫痪——"先学理论再读财报"，永远不开始）**：把读财报无限推迟到"理论学完之后"，结果 90% 的人最后都不会真的去读财报，错失这条普通人挖 10 倍股的最优路径。本 skill 被激活时若发现用户在纠缠"先看什么书"，必须明确把他推到"先动手读一份真实财报"。
- **ce16（不读财报却谈心态——把亏损归咎于"心态不好"）**：投资盈利的核心是认知不是心态。不读财报、不研究行业，只研究"情绪控制"，是认知不足的借口。若用户在亏损后只谈心态、不碰财报，本 skill 应明确指出"心态是认知的结果，去读财报补认知"。

### 作者的盲点 / 时代局限（来自 BOOK_OVERVIEW 批判）

- **关键词扫描 ≠ 严谨财务分析**：作者把读财报降维成"关键词命中"，确实降低了上手门槛，但也可能**漏掉财务粉饰**—— keywords 命中（量价齐升/超预期）完全可以通过确认收入、压货、关联交易、调节出货节奏等方式被人为制造。作者几乎没有教任何识别盈余管理的手段，相信关键词等于相信"景气公司在财报里都说真话"。
- **海量泛读的门槛实际很高**：作者说"一年上千份财报、财报季每天 12 小时"，这要求大量整块时间、稳定的注意力、对产业的基础认知，对绝大多数上班族并不可行；"以量取胜坚持为先"背后是隐性的高门槛，被作者轻描淡写。
- **幸存者偏差 + 后视镜叙事**：作者用 24–26 年 AI 产业链"全产业链量价齐升"作为成功样板（c07），但同样在 2021 年初财报里"量价齐升、景气上行、超预期"的标的（部分新能源、CRO）后来腰斩甚至退市。没有证据表明关键词扫描的前瞻胜率高于市场；这套方法本质是"事后能解释清楚"，不是"事前能保证命中"。
- **案例依赖特定历史阶段**：24–26 AI 含前瞻预测，未必兑现；关键词集合在不同产业周期里命中率会变。

### 容易混淆的邻近方法论

- 与 `deliberate-observation`（刻意观察法）的混淆：两者都是"发现候选"的入口，但信号源不同——刻意观察法的信号来自生活（"突然爆火"），本 skill 的信号来自财报文本（关键词命中）。一条消费股路径，一条财报路径，互补不互斥。
- 与 `industry-alpha-locking`（行业 α 锁定法）的混淆：本 skill 产出的是"有景气信号的候选池"，α 锁定是在候选池里挑核心龙头。先扫描后锁定，顺序不能反。
- 与 `super-growth-stock-criteria`（六条标准）的混淆：六条标准是"够不够格当 10 倍股"的验证器，本 skill 是"去哪里找候选"的检索器。不要把关键词命中当成已通过六条标准——命中只是入场券。
