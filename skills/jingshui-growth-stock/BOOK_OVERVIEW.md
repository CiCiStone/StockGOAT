## 1. 结构 (Structural)

### 类型

方法论 + 实操手册（由"道"及"术"及"人"的成长股投资体系）。

### 一句话主旨

投资的极简之道是：找到当下时代最景气的超级成长股（行业 α），回调分仓介入，**对了死拿、错了砍掉**，通过两三轮产业周期实现财富跃迁。

### 骨架 (主要论点及其关系)

1. **投资之道（第一性原理）**：买股=买公司；极简专注；大机会才是财富跃迁核心。
2. **周期与景气（底层规律）**：万物皆周期，关键是识别拐点；利弗莫尔与巴菲特在"景气度不变"下统一。
3. **价值投资的真相**：区分长线股权投资 vs 景气成长投资；多数人做的是"伪价值投资"；价投有三道高门槛。
4. **选股之法**：超级成长股 6 条标准 + 3 种选股方法 + 锁定每轮行情的行业 α + 不同市场环境的选股方向。
5. **交易之术**：只跟随不预判（创新高）→ 回调分仓买入 → 持盈不止盈 → 基本面拐点止盈/逻辑看错止损 → 仓位风控两条红线。
6. **投研进阶**：财报是核心工具（以量取胜）+ 职业投研日常习惯 + 刻意观察法 + 读书路径 + 复盘历史牛股。
7. **避坑指南**：技术分析是幻象 + 散户七大通病 + 四大误区辨析。
8. **财富与人生**：财富跃迁路径（十年千万）+ 天赋与人格 + 极简主义 + 当下力量 + 真高手画像。

**论点之间的关系**: 层层递进（道 → 法 → 术 → 进阶 → 避坑 → 人），前一层是后一层的依据，"避坑"与"人生"是对核心方法论的加固与升华。全文始终被一句话贯穿："找到景气行业核心 α，回调分仓介入，对了死拿，错了砍掉。"

### 作者要解决的核心问题

普通人如何通过股票投资实现财富跃迁乃至自由？—— 即：如何系统性地**找到、买入并拿住**少数 10 倍级别的超级成长股，同时避开散户通病与技术分析陷阱。

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 超级成长股 / 10倍股 | 当下时代最好、持续超高增速（主营≥40%）、产业趋势向上、供不应求的成长公司 | 不是泛指"成长股"，而是特指**当下时代**的 α，且强调"敢全身价压上" |
| 行业 α / 风暴之眼 | 每轮产业行情中业绩弹性最大、最被资金认可、持续性最强的核心标的 | 借用金融学 α，但作者用它指**每轮行情的龙头/主线票**，非超额收益统计量 |
| 景气度 | 行业/公司处于上升或下降周期的状态，是买卖的唯一核心依据 | 作者把景气度抬到**最高优先级**，高于估值、买卖点 |
| 拐点 | 周期/基本面趋势转换的清晰信号（财报会"清晰展现"） | 强调**财报可观测**，不靠主观预测，反对"猜底" |
| 极简主义 | 把全部精力倾注在超级成长股上，屏蔽一切小机会与垃圾股 | 不只是"少"，而是**主动放弃**所有非核心机会 |
| 持盈止损 | 截断亏损、让利润奔跑——对了死拿、错了砍掉 | 不是一个动作，而是**一套不对称的纪律**：盈利侧宽容、亏损侧果断 |
| 戴维斯双击 | 估值修复 + 业绩增长叠加，诞生 5–10 倍股 | 用于描述风格切换期"被错杀的低位优质成长"的修复行情 |
| 胜兵先胜而后求战 | 先立于不败（只投敢全身价压上的好标的）再求收益 | 反衬"败兵先战而后求胜"——乱抓每个小机会 |
| A8 / A9 / A10 | 资产量级（A8≈千万、A9≈亿、A10≈十亿级，民间用法） | 民间黑话，非正式财富分级 |
| 两类价值投资 | 长线股权投资（垄断/定价权/持续性）vs 景气成长投资（宏观稳定/天花板/增速确定性） | 作者把普通人路径锚定为**景气成长投资** |

### 核心命题 (用自己的话)

1. 买股票就是买公司，赚企业成长的钱，而非博弈价差。
2. 极简专注：敢不敢把全部身价压上去，是唯一的标的筛选器。
3. 财富跃迁靠的是隔三岔五抓住一次爆炸性 10 倍机会，不是每年稳赚 20%。
4. 万物皆周期，关键是识别拐点；没有拐点的行业不抄底。
5. 利弗莫尔（趋势/买涨确立）与巴菲特（价值/买错杀）在"景气度不变"前提下殊途同归。
6. 普通人应走景气成长投资路径；长线股权投资只适合超大资金。
7. 超级成长股有 6 条硬标准，缺一不可（管理层增持可放宽）。
8. 选股只有三种方法：成长观察法、财报选股法、周期选股法。
9. 每轮行情都要锁定行业 α；强者恒强，买杂毛会被虹吸。
10. 趋势识别最简标准=股价创历史新高。
11. 回调分仓分批买入，越跌越买只适用于景气度不变的核心成长股。
12. 持盈不止盈，接受 30–40% 正常回撤；卖飞比套牢更致命。
13. 止盈唯一依据=基本面拐点（不逃顶）；止损=逻辑看错/基本面拐点（越亏越补是恶习）。
14. 两条绝对红线：绝不加杠杆、绝不单吊梭哈；分仓降风险且不损收益。
15. 财报是普通人挖掘 10 倍股最便捷路径，以量取胜、坚持为先。
16. 技术分析（含缠论）是逻辑自洽但非本质的幻象，会偷走"选股"注意力。
17. 散户七大通病（穷人思维/恐高/拿不住/不止损/频繁交易/爱预判/分散注意力）是亏钱主因。
18. 财富自由靠投资不靠工作；十年千万有清晰可执行的五阶段路径。
19. 认知到位，财富只是附属品。

### 论证链

作者的论证路径：先立"投资本质=买好公司成长"（第一性原理）→ 推出"必须极简专注少数大机会"→ 用"万物皆周期+景气度"解释何时买卖 → 给出可操作标准（6 条选股 + 3 种方法 + 交易纪律 + 风控红线）→ 用"避坑+散户通病+误区"反向加固（不这样做会怎样）→ 升华到认知/人生。

**证据类型**：主要为 ① 历史牛股案例（19–20 茅台/汾酒、21–23 宁德/天齐、24–26 光模块/算力等）；② 作者个人投资经验与观察；③ 对散户行为的反面归纳。**注意**：几乎没有量化回测或统计胜率，是典型的经验归纳 + 后视镜叙事。

## 3. 批判 (Critical) ★

### 作者的时代局限

- 全文紧绑 A 股且案例高度依赖特定历史阶段（19–20 吃药喝酒、21–23 新能源、24–26 AI）；其中"24–26 AI"含前瞻预测，未必兑现。
- "股价创新高=最强信号""强者恒强"等前提，依赖特定流动性环境与产业周期；若市场结构（注册制/退市/资金生态）变化可能失效。
- "A8/A9/A10""十年千万"预设了 A 股长期存在大量超级成长股与高波动机会，本身是周期性假设。

### 作者的立场盲点

- **幸存者偏差**：作者是成功者，只讲"做到了"的路径，不讲"同样方法但失败"的多数人。
- 把"单票腰斩很常见"轻描淡写，淡化该策略在熊市/震荡市或买错时的毁灭性回撤。
- 对"技术分析/择时"一刀切否定，可能忽略了择时对风控的补充价值。
- 隐含假设读者能承受 50%+ 回撤与长期浮亏，对绝大多数普通人不可承受。
- "敢全身价压上才买"（筛选器）与"分仓不梭哈"（执行）存在张力，容易被读者误读为重仓单吊。

### 未被证明的假设

- "好公司股价永远不便宜""强者恒强"被当公理，但历史上无数"强者"陨落（诺基亚、教培、部分白酒），作者以"惯性"一笔带过。
- "复利后期馈赠远超想象"假设能扛到后期，未证明普通人扛得住。
- "两轮牛市抓 2 只 10 倍股就财富自由"把极难的识别+拿住说成"只要坚持"。
- "短线趋近赌博、几乎没人做大"是断言，缺统计支撑。
- "INTJ/INTP 是投资先天圣体"属 MBTI 玄学，无实证。

### 最强反对意见

> 这是典型的**幸存者偏差 + 后视镜叙事**。作者列出的每只"10 倍股"都是事后选出的赢家；在 2021 年初同样符合"6 条标准 + 创新高 + 景气"的标的（部分新能源、CRO）后来腰斩甚至退市。没有证据表明这套方法的前瞻胜率高于市场；"回调分仓买入 + 死拿"在**买错时恰恰是加速亏损**（作者自己也承认单票腰斩常见）。把一个本质上需要极高信息优势、心理承受力与运气的方法包装成"普通人也能做到"，可能误导人重仓高风险成长股。

> **以上批判会直接成为下游 skill 的 Boundary (B) 字段来源**
