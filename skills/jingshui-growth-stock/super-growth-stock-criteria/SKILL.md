# 超级成长股六条标准

## R — 原文 (Reading)

> "符合以下全部标准的标的，就是能涨10倍的超级成长α，其中管理层增持可适度放宽：①业绩硬增速（主营≥40%，不买亏损）②新增长动能（新产能/新品/新应用场景持续兑现）③强供需矛盾（供不应求的卖方市场）④充足想象力（市场天花板高）⑤市场认可度（股价创一年以上新高）⑥管理层背书（增持/激励，此项可放宽）。没有业绩、纯炒概念的标的直接排除；主营增速低于40%的不买，亏损公司不买。"
>
> — 静水2008，第二章 第4节

---

## I — 方法论骨架 (Interpretation)

这是一张用来回答"这只股到底够不够格成为10倍股"的六维硬标准清单。核心思路是：与其凭感觉判断"这家公司好不好"，不如把判断拆成六个可以逐一查证、逐一打分的维度，六个维度必须同时达标（缺一不可），这只股才算"够格"。

六个维度分别回答：
1. 业绩硬增速——它现在的成长有多快？（主营增速≥40%是硬门槛，且不买亏损公司）
2. 新增长动能——它接下来的成长引擎在哪？（新产能/新品/新应用场景在持续兑现，而不是吃老本）
3. 强供需矛盾——它的产品是不是"卖方市场"？（下游排队、接受高溢价、产线满产，而不是求着人买）
4. 充足想象力——它所在赛道的天花板够不够高？（市场还能持续扩张多年，而不是已经见顶）
5. 市场认可度——股价是否已经创一年以上新高？（创新高=所有资金认可、套牢盘解放，是"市场用真金白银投票"的客观证据）
6. 管理层背书——管理层自己有没有在增持或做激励？（这一条可以适度放宽，但有则加分）

关键在于"六条全中"——任何一条硬伤（增速不够、纯炒概念、景气向下）就直接淘汰，不要试图用其他维度的高分去补。第6条管理层背书是唯一允许放宽的维度。

这套标准的反直觉之处：它明确反对"买便宜/低估值"的常识——好公司股价永远不便宜，创新高的强势股才是高概率候选；同时反对"看质地"这种含糊判断，要求用可验证的财报数据和价格信号做硬判定。

## A1 — 书中的应用 (Past Application)

### 案例 1: 20-21年消费牛市——茅台、汾酒、药明康德、片仔癀通过六维过滤

- **问题**: 一轮消费牛市来了，哪些票是"能涨10倍"的超级成长α，哪些只是杂毛？
- **方法论的使用**: 作者把这批标的放到六维框架下检验——业绩持续高增速（茅台/汾酒的量价齐升、药明/片仔癀的订单饱和）、新增长动能（高端白酒提价+产能扩张、CXO订单持续超预期）、强供需矛盾（白酒供不应求、CXO产能满载下游排队）、充足想象力（消费升级+医药外包长周期）、市场认可度（持续创一年以上新高）、管理层背书（多数有增持或激励）。
- **结论**: 六条全部命中的是核心α；只命中几条或景气向下的（部分跟风白酒）是杂毛，会被核心α虹吸资金。
- **结果**: 这批标的在20-21年消费牛市中持续创新高、业绩持续超预期，验证六维过滤的有效性。

### 案例 2: 21-22年新能源牛市——宁德时代、天齐锂业、天赐材料、恩捷股份

- **问题**: 新能源行情里，哪些是真正的10倍级α？
- **方法论的使用**: 同样用六维检验——业绩硬增速（宁德/天齐业绩爆发，量价齐升）、新增长动能（锂电池/锂矿产能持续扩张）、强供需矛盾（锂矿供不应求、电池产线满产下游排队抢货）、充足想象力（新能源车渗透率从个位数往高位）、市场认可度（持续创一年以上新高）、管理层背书。共同特征：持续创新高+业绩持续超预期+明显的板块效应。
- **结论**: 六维全中的是新能源行情的行业α；买杂毛（同板块弱势股）会出现"它涨你跌"。
- **结果**: 这批标的在21-22年新能源牛市中走出超级成长股行情，是六维框架的典型样本。

### 案例 3: 24-26年AI牛市——光模块、PCB及设备、算力、半导体设备、存储

- **问题**: 这轮AI行情里，哪些方向够格成为核心α？
- **方法论的使用**: 作者用财报信号反向印证六维——AI产业链在财报中清晰展现"全产业链量价齐升、供不应求、新品超预期、市场规模持续扩大"，对应强供需矛盾+新增长动能+充足想象力+业绩硬增速；股价持续创新高对应市场认可度。
- **结论**: 光模块/PCB及设备/算力/半导体设备/存储是24-26年AI行情的核心α池。
- **结果**: （含作者前瞻判断）这批方向在24-26年AI行情中持续创新高、业绩持续超预期。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **拿着一只具体股票来问"这只能不能涨10倍"** —— 用户已经有一个标的（比如某只热门股、朋友推荐的票、自己研究中的公司），想要一个客观的标准清单来判定它够不够格。
2. **在多个候选里做减法** —— 用户面对一堆候选票，需要用硬标准逐条过滤，淘汰不合格的，留下少数几个值得深度研究的。
3. **担心自己买的是"概念股/杂毛"** —— 用户想确认手里的票是真超级成长股还是纯炒概念、同板块弱势股。
4. **想给一只股做结构化体检** —— 用户希望得到一个六维打分表，看清这只股强在哪、弱在哪、哪条是硬伤。
5. **怀疑"便宜就是机会"** —— 用户被低价/低位股吸引，需要用六标准纠正"贪便宜"的穷人思维。

### 语言信号 (用户的话里出现这些就应激活)

- "这只股能不能涨10倍？" / "这只算不算超级成长股？" / "帮我过一遍六条标准"
- "这只股值不值得重仓？" / "这只够格吗？" / "它符合你的成长股条件吗"
- "帮我把XX股筛一下" / "这几只里哪些是杂毛"
- "is this a 10x stock?" / "does it meet the six criteria?" / "super growth stock checklist"
- "它业绩40%以上，能不能买？" / "这股创新高了，是不是10倍苗子"

### 与相邻 skill 的区分

- 与 `industry-alpha-locking` 的区别（初稿）: α锁定法回答"这一轮行情该选哪只"——是横向选标的（当下最景气行业+核心α是谁）；本 skill 回答"这只股够不够格"——是纵向做资质判定（六维硬标准打分）。先用 α 锁定法圈定候选池，再用本 skill 给候选逐只打分。
- 与 `prosperity-and-inflection` 的区别（初稿）: 景气度判断回答"这个行业现在处于周期什么位置、拐点到了没"——是六标准的前提条件（行业不景气，单只股再好也不该重仓）；本 skill 是在"景气度向上"已确认后，对具体标的做硬资质过滤。景气度是总开关，六标准是标的筛选器。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **收集这只股的六维证据**
   - 动作：逐一查证六个维度——①最近一期主营增速是否≥40%、是否亏损；②有没有新产能/新品/新应用场景在持续兑现；③产品是否处于供不应求/产线满产/下游排队/下游接受高溢价的卖方市场；④所在赛道天花板是否够高（用渗透率/市场规模/增速判断）；⑤股价是否创一年以上新高；⑥管理层是否有增持或股权激励。
   - 完成标准：六个维度各有一条带证据来源的判定（"命中/未命中/证据不足"），而不是凭印象说"应该不错"。

2. **逐条打分并定位硬伤**
   - 动作：把六维结果列成清单，标出哪几条命中、哪几条未命中。重点找"硬伤"——业绩增速<40%、纯炒概念无业绩、景气向下、非卖方市场。
   - 完成标准：输出一张六维打分表，明确指出有无硬伤、哪条是硬伤。
   - 判停条件：若维度①（业绩硬增速）或③（强供需矛盾）未命中，且不是"管理层背书可放宽"类问题 → 直接判定"不够格"，跳到步骤4给出淘汰结论，不再往下评估。若仅维度⑥管理层背书未命中，其余五条全中，标记"可放宽"继续。

3. **做"六条全中"判定，不要用其他维度的高分去补硬伤**
   - 动作：判定逻辑是"AND 不是 OR"——任何一条硬伤即淘汰，不允许"业绩差但赛道好"这种补偿式打分。唯一允许放宽的是第⑥条管理层背书。
   - 完成标准：给出明确结论——"六维全中（或五中+管理层放宽）= 够格，进入候选池"或"有硬伤=不够格，淘汰并说明哪条淘汰"。

4. **如果够格，提示前置依赖；如果不够格，给替代方向**
   - 动作：够格的标的，提醒用户"这只是够格，能不能买还要先看行业景气度（用 prosperity-and-inflection）和该买哪只（用 industry-alpha-locking）"；不够格的标的，明确告诉用户问题出在哪、是杂毛还是纯概念，建议放弃或转向同板块的核心α。
   - 完成标准：用户拿到的是一个"够格/不够格"的明确判定 + 下一步该用哪个 skill 的指引。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **行业景气度未确认时直接拿单只股打分** —— 六标准的前提是行业景气度向上。若行业整体向下，单只股六维再漂亮也只是后视镜。必须先用 `prosperity-and-inflection` 确认景气度，再用本 skill。
- **想问"该买哪只"时** —— 这是 `industry-alpha-locking` 的职责（横向选标的）。本 skill 只回答"这只够不够格"（纵向判定）。
- **想问"什么时候买/卖"时** —— 本 skill 不涉及买卖点、仓位、止盈止损。买卖用 `trend-following-entry`/`scale-in-and-risk-control`/`hold-or-cut-exit`。
- **纯概念股/题材股/亏损公司** —— 这类标的连维度①都过不了，不需要走完整六维，直接在第1步淘汰即可。
- **想用"便宜/低估/安全边际"作为买入理由时** —— 六标准明确反对"贪便宜"逻辑，用户带这种预设来不会被满足。

### 作者在书中警告的失败模式

- **ce02 研究买卖点而忽视公司质地**：把精力花在 K 线/技术位/买卖点上，却不去验证标的是不是超级成长股——择时再准也只赚小钱，甚至买在垃圾股的"完美买点"上亏大钱。本 skill 正是用来对抗这种本末倒置。
- **ce08 穷人思维——偏爱便宜垃圾股**：系统性偏好低价/低位/便宜股，认为"便宜=安全"，实际买入的是基本面持续恶化的公司。六标准要求"创新高+供不应求"，直接否决这类"便宜货"。
- **ce19 买杂毛被核心α虹吸**：在主线行情中买同板块非核心标的（不满足六标准的"伪成长"），不但享受不到超额收益，还会被核心α虹吸资金出现"它涨你跌"。

### 作者的盲点 / 时代局限

- **六条标准是后视镜归纳**：作者列出的每只"10倍股"都是事后选出的赢家。在2021年初同样符合"六标准+创新高+景气"的部分新能源/CRO标的，后来腰斩甚至退市。没有证据表明这套标准的前瞻胜率高于市场。本 skill 给出的是"够格判定"而非"一定会涨10倍"的保证。
- **幸存者偏差**：作者是成功者，只讲"做到了"的路径。同样用六标准筛选但失败的多数人未被记录。用户应把本 skill 当作"降低选中垃圾股概率"的过滤器，而非"包赚10倍"的公式。
- **24-26年AI案例含前瞻预测**：A1案例3中的AI方向是作者的前瞻判断，未必全部兑现。用六标准评估当下AI标的时，需自行验证财报数据，不要照搬案例结论。
- **"创新高=最强信号""强者恒强"依赖特定流动性环境**：若市场结构（注册制/退市/资金生态）变化，"创新高"作为第⑤条标准的判别力可能下降。
- **"敢全身价压上"与"分仓不梭哈"的张力**（ce28）：六标准是"质量门槛"，通过六标准的标的不等于"该重仓单吊"——执行层面仍需分仓（见 `scale-in-and-risk-control`）。不要把"够格"误读为"梭哈指令"。

### 容易混淆的邻近方法论

- **与价值投资选股标准混淆**：传统价值投资看"垄断性/定价权/持续性/低估值"，作者明确指出那是长线股权投资（适合超大资金，全A股不超过20家）；本 skill 的六标准是景气成长投资路径（看增速/供需/新高），两套标准不可混用。
- **与技术分析的"创新高"信号混淆**：作者第⑤条"创新高"是"市场所有资金认可"的基本面验证，与"突破前期高点的K线事件"不同——必须绑定在"好公司"上才有意义，对基本面恶化的标的新高无意义。
