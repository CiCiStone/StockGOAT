# 真假价值投资辨析（两类价投 + 四大误区）

## R — 原文 (Reading)

> "长线股权投资：看垄断性、定价权、持续性；景气成长投资：看宏观稳定、行业天花板、业绩增速确定性，是普通人更易落地的路径。绝大多数人打着价投旗号亏钱，因为买的是景气度下行、基本面恶化的标的，完全缺失核心上涨逻辑……这不是价投，是傲慢。"
>
> — 静水2008，第一章 第3节、第五章 第20节

---

## I — 方法论骨架 (Interpretation)

"价值投资"在作者体系里不是一个动作(长期持有)，而是一套**有前提的能力门槛 + 一套看什么**的框架。
先把价投拆成两类：长线股权投资看"垄断性/定价权/持续性"，整个 A 股满足标准的不超过 20 家，
只适合超大资金；景气成长投资看"宏观稳定/行业天花板/增速确定性"，是普通人该走的路径。
其次，绝大多数散户做的是**伪价投**——买景气度下行的标的，却用"长期持有"包装硬扛。
判真伪的唯一标尺是**景气度方向**(向上=真，向下=伪)，与持有时长、自我标签、是否亏钱都无关。
再破四个流行误区：①长线持有≠价投(前提是好公司)；②越跌越买有前提(限基本面不变的超成长)；
③亏损归因是认知不足不是心态；④短线无法快速致富(有资金量天花板，A9/A10 全是中长线)。
一句话：价投是"能力 + 标的 + 方向"三重合格之后的结果，不是亏损时的自我安慰。

## A1 — 书中的应用 (Past Application)

### 案例 1: 19-20 年吃药喝酒行情=对应阶段的"价值投资主线"(c01)

- **问题**：什么是"真正的价值投资"？是抱某些永恒赛道、还是某种持有动作？
- **方法论的使用**：作者用 19-20 吃喝吃药、21-23 新能源、24-26 AI 泛科技三段行情举例，说明"真正的价投是持续躺在 10 倍股上获取超额收益"——所谓价投主线并非永恒赛道，而是**每个时代最景气的主线**。当年躺在白酒/医药 10 倍股上的是真价投，因为它们的景气度那时是向上的。
- **结论**：价值投资的"真"绑定在"对应阶段的景气主线 + 持续超额收益"上，不在某个固定行业或"长期持有"这个动作上。
- **结果**：19-20 吃药喝酒赛道走出大量 5-10 倍股，验证了"对应阶段价投主线"命题——同时反衬出抱着刻板印象抄下行周期白酒的人，做的不是价投而是伪价投。

### 案例 2: 白酒去库周期被不停抄底=伪价投反面教材(c02)

- **问题**：行业去库周期中的白酒，业绩持续下滑，为什么那么多人还在不停抄底并自称"长期持有"？
- **方法论的使用**：作者直接定性：这是"打着价投旗号亏钱"的典型。其本质是标的的**景气度已向下**(行业去库、业绩下滑、基本面恶化)、**核心上涨逻辑已缺失**，但散户仍凭"白酒=好赛道"的刻板印象执行越跌越买，并用"长期持有"自我合理化。判真伪不看他们持有多久、是否自称价投，只看景气度方向。
- **结论**：景气度向下时，"长期持有 + 越跌越买"不是价投，是傲慢——持有越久亏得越多。
- **结果**：作者断言此类伪价投"必然亏钱"，是绝大多数人打着价投旗号亏损的总根源。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **长期持有却持续亏损，开始怀疑自己**：用户拿着浮亏标的，反复说"我是价投/我学巴菲特长期持有/是不是要再熬几年"，需要核查是真价投还是伪价投。
2. **下跌中纠结要不要越跌越买 / 补仓**：手里标的跌了 30-50%，想用"巴菲特说便宜时买优秀公司"为补仓辩护，需要校验前提(标的是不是超成长、景气度变没变)。
3. **复盘亏损时把锅甩给"心态"**：反复说"当时太贪/太慌/没控制住情绪"，需要指出真正缺口是认知与体系而非情绪。
4. **想做短线快速致富 / 资金目标定在 A8-A9 却主要做短线**：把短线/打板/日内当致富路径，需要认清资金量天花板与中长线才是财富跃迁通道。
5. **新人入市要在"两类价投"里选路径**：问"我该学巴菲特还是学景气成长 / 普通人怎么做价投"，需要按资金体量与能力门槛对号入座。

### 语言信号 (用户的话里出现这些就应激活)

- "我是做价值投资的 / 我在长期持有 / I'm a value investor, I hold long-term"
- "巴菲特也长期持有，为什么我亏 / Warren Buffett holds forever too"
- "越跌越买对不对 / 该不该补仓摊平成本 / is averaging down right"
- "我这只股基本面没问题，就是心态不好 / my mindset was off"
- "短线能不能快速致富 / 打板能不能做到 A8 / can short-term trading make me rich"
- "普通人该走哪条价投路 / 长线股权 vs 景气成长怎么选"
- "白酒/医药/某某赛道是价投吧，跌了是不是该抄底"

### 与相邻 skill 的区分（初稿，阶段 3 回填定稿）

- 与 `seven-retail-sins` 的区别：那个 skill 是**行为通病自检清单**(穷人思维/恐高/拿不住/不止损/频繁交易/爱预判/分散注意力)，逐条诊断"做了什么错动作"；本 skill 是**认知误区辨析**，诊断"你以为是价投、其实不是"的身份与前提错配。一个查动作，一个查自我标签是否成立。
- 与 `prosperity-and-inflection` 的区别：那个 skill 教"**景气度方向怎么测出来**"（证据收集与拐点确认方法）；本 skill 用它**测出来的结论**去判真伪价投。本 skill 不重新测景气度，而是直接调用"景气向上=真/向下=伪"这一判据。两者协同：prospersity 是判据提供者，本 skill 是判据的应用者之一。
- 与 `hold-or-cut-exit` 的区别：那个 skill 教"识别伪价投之后**怎么根治**——拐点止损/止盈动作"；本 skill 教"**先认出**这是伪价投"。本 skill 是它的前置诊断，那个 skill 是后置执行。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **校验"价投"标签的三道能力门槛（f07）**
   - 让用户自检能否同时做到：①准确识别标的是否优质资产；②对标的科学估值；③持续跟踪并精准捕捉拐点。任一门槛过不了，就不该自认在做价投。
   - 完成标准：明确给出"用户当前是否够格自称价投"的结论，并指出卡在哪道门槛。
   - 判停条件：若用户连"识别优质资产"都未做到(对标的基本面一无所知) → 直接判伪价投，跳到步骤 3。

2. **调用景气度方向判定真伪（核心判据，由 prosperity-and-inflection 提供）**
   - 不看持有时长、不看自我标签、不看是否浮亏——只看标的的**景气度方向**：景气向上 = 真价投；景气向下 / 基本面恶化 = 伪价投。
   - 证据来源：最新财报(营收增速/订单/价格中枢)、行业研报(供需格局/行业增速)、公司交流/调研纪要、新闻政策。
   - 完成标准：用景气度方向给出"真价投 / 伪价投"的明确判定，并标注证据。
   - 判停条件：若证据不足以判断景气方向 → 告知用户"暂无法判真伪，先补财报与产业证据"，不轻易下"真价投"结论。

3. **逐项破除四大误区（按用户措辞对号）**
   - 误区 1"长线持有=价投"：补前提——标的必须是好公司(超级成长股)，垃圾股越拿亏越多(ce14)。
   - 误区 2"越跌越买=对"：补前提——只限基本面不变的超级成长股；基本面已恶化则越跌越买=加速亏损(ce15)。
   - 误区 3"亏损=心态不好"：纠正归因——盈利核心是认知不是心态，归咎心态是认知不足/体系残缺的借口(ce16)。
   - 误区 4"短线=快速致富"：指出天花板——短线有资金量天花板，做到 A9 几乎天堑，A9/A10 全是中长线(ce17)。
   - 完成标准：针对用户原话点出对应误区编号，给出"被偷换的前提"和正确表述。

4. **给出路径选择与后续动作建议（与相邻 skill 协同）**
   - 若判定伪价投 → 强制建议转 `hold-or-cut-exit` 执行拐点止损(根治方式)，并明确"越跌越买立即失效"。
   - 若是真价投但标的选错路径(普通人走长线股权) → 建议改走景气成长投资路径，转 `super-growth-stock-criteria` 重选标的。
   - 若用户主要做短线却定 A8/A9 目标 → 建议转中长线成长投资框架。
   - 完成标准：动作建议明确挂在步骤 2 的真伪判定与步骤 3 的误区编号上，指向具体相邻 skill，不停在"调整心态"层面。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用户只想学"怎么选股/怎么买卖"时**：本 skill 是辨析与诊断类(查标签与前提)，不教选股六条标准、不教回调分仓、不教拐点止盈。具体动作转 super-growth-stock-criteria / scale-in-and-risk-control / hold-or-cut-exit。
- **标的已是超级成长股、问题在卖点执行时**：那种情况不是"伪价投身份错配"，而是"卖点动作没做"，转 hold-or-cut-exit。
- **只想测景气度方向本身时**：本 skill 调用景气度结论做判定，不重新做证据收集；要测方向转 prosperity-and-inflection。
- **想用本 skill 为亏损硬扛找理由时**：本 skill 的方向是**揭穿**伪价投，不是为"长期持有"提供合理化话术。若用户期待本 skill 说"再熬几年就是真价投"，应明确拒绝并指出 ce04 的失败模式。

### 作者在书中警告的失败模式

- **ce04 伪价值投资=傲慢**：以"价值投资/长期持有"为名义，持续加仓景气度下行、基本面恶化的标的，把"傲慢和死扛"包装成"信仰"。警告信号：用"巴菲特也长期持有"为亏损股辩护；持仓公司连续多季度业绩下滑却拒绝重新评估；把读财报视为"短期行为"而拒绝。作者明确定性："这不是价投，是傲慢。"
- **ce14 长线持有≠价投**：对任何标的都套"长期持有"逻辑，把"时间维度"当成"质量维度"。时间是好公司的朋友、是烂公司的敌人——持有垃圾股越久价值毁灭越多。警告信号：用"我是长期投资"为亏损股辩护、长期持有却不长期跟踪财报、标的多作负收益仍坚持"长期"。
- **ce15 越跌越买有前提**：不区分"基本面不变"还是"基本面恶化"，对一切下跌都执行越跌越买，在恶化标的上加速亏损。前提是"超级成长股 + 景气度不变"，脱离前提就是把巴菲特金句抽掉上下文滥用。警告信号：用巴菲特名言为下跌补仓辩护却不验证基本面、把越跌越买当无前提铁律、补仓标的已现景气向下拐点仍执行。
- **ce16 心态归因**：用"心态不好"解释亏损，把系统性缺陷包装成情绪问题，阻止认知迭代。心态是认知的结果而非原因——对行业公司有透彻认知、形成完整体系时，心态问题自然消失。警告信号：复盘反复说"太贪/太慌"、不读财报只研究"情绪控制"、同一类错误反复犯。
- **ce17 短线致富幻想**：把短线当快速致富路径，资金到一定量级后无法放大(流动性、冲击成本)，且越短越趋近赌博。作者断言"做到 A9/A10 没有一个是短线"。警告信号：资金目标 A8/A9 却主要做短线、频繁切换策略追求"快"、把日内/打板当主要手段。

### 作者的盲点 / 时代局限（来自阶段 0 批判）

- **对"价值投资"的定义偏窄、把景气成长也归为价投是个人分类**：BOOK_OVERVIEW 批判段指出，作者把"价值投资"二分为长线股权 vs 景气成长并自称两类都是"价投"，这是**作者个人的分类法**，与主流(格雷厄姆-巴菲特-芒格)对价值投资的定义(以低于内在价值买入、强调安全边际与护城河)并不完全一致。主流价投里"垄断/定价权/持续性"恰恰是核心，而作者把"长线股权"框定为"只适合超大资金、整个 A 股不超 20 家"，带有明显的个人取舍——读者需知这是分类偏好，不是学术共识。
- **"伪价投"判据高度依赖景气度，而景气度本身难测**：判真伪的唯一标尺是景气度方向，但景气度判断依赖信息优势与产业跟踪能力(公司交流、调研纪要、研报)，普通散户未必能平等获取；"清晰展现拐点"是经验性表述、无量化阈值。在证据不足时，"景气向上=真价投"的判定本身就有主观裁量空间，存在"误判为真价投而死扛"的隐性风险。
- **"做到 A9/A10 全是中长线、没有例外"是断言**：ce17 的"没有例外"缺统计支撑，存在成功短线大资金的反例(虽是少数)；把短线路径整体否定是作者立场，非可证伪结论。
- **"长线股权投资只适合超大资金"是取舍不是公理**：作者把普通人路径锚定为景气成长，部分原因是景气成长"更易落地"而非长线股权"不正确"；中小资金同样可以做长线股权(垄断/定价权型)投资，只是作者体系不主推。读者应知这是路径推荐，非排他判定。
- **A 股 + 特定历史阶段假设**：19-20 吃喝喝酒、21-23 新能源、24-26 AI 三段"对应阶段价投主线"依赖特定产业周期；"白酒去库=伪价投"在白酒重新进入上行周期后判定会反转——本 skill 的真伪判定**会随周期翻转**，不是一次性永久标签。

### 容易混淆的邻近方法论

- 与 `seven-retail-sins`：那个查**行为通病**(做了什么错动作)，本 skill 查**认知误区与身份错配**(你以为自己是谁)。一个用户可能同时两者都有：动作层频繁交易(seven-retail-sins 的通病 5)、认知层却自命价投(本 skill 的伪价投)。两者互补不互斥。
- 与 `prosperity-and-inflection`：那个教"景气度**怎么测**"，本 skill 用"测出来的方向**判真伪**"。混淆会让本 skill 越界去重新做证据收集，丧失辨析的纯粹性——正确做法是调用那个 skill 的结论。
- 与 `hold-or-cut-exit`：那个教"识别伪价投后**怎么砍**"，本 skill 教"**先认出**是伪价投"。先诊断(本 skill)再执行(那个 skill)，顺序不能颠倒。
- 与 `minimalist-focus`：那个是"敢全身价压上才买"的**筛选器**，本 skill 是"你以为是价投、其实不是"的**揭穿器**。前者用于入场前筛标的，后者用于持仓中查标签。
