## 二、数据分析规范

### 写作原则：结论先行，详细展开

每个分析步骤、每个子议题，**禁止只写结论或只列表格**。采用两层结构：

```
【结论提要】1-3 句话：判断方向 + 核心依据（读者可快速把握）
【详细调研】完整推理过程，须包含：
  - 数据事实：具体数字、时间、来源链接
  - 逻辑链条：A（事实）→ B（机制）→ C（对公司的影响）
  - 调研细节：产能、价格、政策、竞争格局等可验证信息
  - 反面论证：什么情况下结论可能不成立
【小结】表格或一句话，收束本节（表格是归纳，不能替代正文）
```

> 表格、emoji 标记是**归纳工具**，不能替代中间的推理和调研细节。  
> 章节较长时，用 `【结论提要】` 做小标题，方便跳读；展开部分不可省略。

### 时间维度：默认看近三年

**禁止只拿「上一年 vs 当年」做同比就下结论。** 凡涉及财务、价格、产能、市占率、估值分位等时序数据，**默认拉齐近三年（T-2、T-1、T）**，必要时补充最新季报作第四列：

| 要求 | 说明 |
|------|------|
| 财务指标 | 营收、净利、扣非、毛利率、ROE、现金流等：**2023 / 2024 / 2025** + 最新季报 |
| 商品价格 | 主力合约或现货：**近三年均价 + 涨跌幅**，说明处于周期哪一段 |
| 业务数据 | 产量、贸易量、市占率：三年趋势，不单列一年 |
| 估值 | PB/PE 近三年分位或区间，说明当前定价在历史中的位置 |
| 逻辑分析 | 先描述**三年趋势形态**（如「营收连增但扣非三年皆亏」），再解释当年变化 |

```
【三年趋势提要】一句话概括三年方向（上行/下行/拐点/震荡）
【详细调研】
  - 三年数据表（必填）
  - 趋势解读：拐点出现在哪一年、驱动因素是什么
  - 当年（T）变化放在三年脉络中理解，而非孤立同比
【小结】
```

### 步骤1：公司基本面

**须搜集**：股票代码、股价、PB、PE、总市值；主要业务及收入占比；实控人；产业链位置。

**写作格式**：

```
【结论提要】公司是什么、核心投资逻辑/风险一句话
【详细调研】
  - 股权与治理：实控人、大股东结构、国企改革/政策背景
  - 业务拆解：各板块收入/毛利/产能，经营模式（直销/贸易/代工）
  - 产业链位置：上游←本公司→下游，公司在链条中的议价能力
  - 历史沿革：并购、资产注入、战略转型等影响当前估值的事件
【小结】关键指标表（代码、市值、PB、核心业务占比）
```

---

### 步骤1b：财务分析（报告第二章，与基本面配套）

**写作格式**：

```
【结论提要】盈利/亏损状态、现金流质量、财务健康度一句话

【详细调研】
  1. 核心指标表：**近三年（T-2/T-1/T）** + 最新季报，营收/净利/毛利/ROE/负债率等
  2. 盈利质量：
     - 利润与经营现金流是否匹配，差异原因
     - 扣非 vs 归母，非经常性损益影响
  3. 亏损/盈利原因拆解（逻辑链，非罗列）：
     - 价格因素（产品单价变动 × 销量）
     - 成本因素（原料、人工、折旧）
     - 一次性因素（减值、汇兑、公允价值变动）
     - 各因素对利润的贡献量化（尽可能）
  4. 资产负债：货币资金 vs 有息负债、存货规模与跌价风险、商誉
  5. 亮点与隐患：分别展开论据

【小结】财务健康度表 + 后续跟踪指标
```

### 步骤2：行业分析（上下游必须都调研，不可偏废）

#### 2a. 上游（成本端/供给约束）

逐个分析主要原材料（占比显著或价格敏感者必写），**每个原料**按两层结构：

```
#### 原料名称（占成本约 XX%）

【结论提要】
  短期：🔴/⚪/🟢 偏多/中性/偏空 — 一句话
  长期：🔴/⚪/🟢 偏多/中性/偏空 — 一句话

【详细调研】
  1. 现状（数据）
     - 当前价格/产量/库存/进口依存度，注明来源链接
     - **近三年价格或供需走势**（不能只写当年）
     - 主要产地与格局（谁供给、集中度如何）
  2. 逻辑链条
     - 供给端：产能、开工、天气、政策 → 如何影响价格
     - 需求端：下游开工、替代品 → 如何传导至该原料
     - 对本公司：价格变动 × 成本占比 → 毛利/存货/套保影响
  3. 短期（1年）判断与理由
     - 列出 2-3 条支撑论据 + 1 条风险/反面情形
  4. 长期（3-5年）判断与理由
     - 产能周期、技术替代、政策方向
  5. 结论：一句话收束 + 对公司的具体影响路径

【本节小结】（可选，单原料可省略）
```

**章节末尾**必须有 **上游小结表**（原料 × 短/长期判断 × 对公司影响），表前用 1-2 句概括上游整体态势。

#### 2b. 下游（需求端/市场天花板）

逐个分析主要消费领域（占比 >5% 必写），**每个领域**同样两层结构：

```
#### 下游领域名称（占需求约 XX%）

【结论提要】
  短期：🔴/⚪/🟢 — 一句话
  长期：🔴/⚪/🟢 — 一句话

【详细调研】
  1. 现状（数据）
     - 市场规模、增速、集中度；本公司客户/份额/合作模式
  2. 逻辑链条
     - 终端景气（汽车、地产等）→ 本领域需求 → 本公司订单/销量
  3. 短期 / 长期判断与理由（论据 + 反面情形）
  4. 结论：对本公司收入与定价的影响

【本节小结】（可选）
```

**章节末尾**必须有 **下游小结表** + **一句话总判断**（下游整体对公司是顺风还是逆风）。

#### 判断标记规范（A股红涨绿跌，与西方惯例相反）

| 标记 | 含义 | 文字色 | HTML类 | 色值 |
|------|------|--------|--------|------|
| 🔴 | **偏多/利好**（对公司有利） | 红 | `.pos` | `#dc2626` |
| 🟢 | **偏空/利空**（对公司不利） | 绿 | `.neg` | `#16a34a` |
| ⚪ | **中性**（无明确方向） | 灰 | `.neu` | `#94a3b8` |

> **注意**：emoji 颜色与 A 股行情色一致——🔴 代表利好/上涨，🟢 代表利空/下跌。勿与西方「绿好红坏」习惯混淆。

### 步骤3：估值分析

**方法选择**（须写明为何用该方法）：

| 公司类型 | 估值方法 |
|----------|---------|
| 成熟稳定盈利 | PE（市盈率） |
| 高成长未盈利 | PS（市销率） |
| 重资产/周期股 | PB（市净率） |
| 大公司 | 分部估值法 |
| 投资股权 | 市价折价或账面价值 |

**写作格式**：

```
【结论提要】合理估值区间 X-Y 元，当前定价偏贵/合理/偏便宜，一句话理由

【详细调研】
  1. 方法选择：为何用 PB/PE/PS，公司处于周期哪一阶段
  2. 当前定价：市值、PB/PE、与历史分位、与行业均值对比（附数据表）
  3. 同行对比：至少 2-3 家，列表说明业务差异为何可比/不可比
  4. 估值推算：
     - 悲观/中性/乐观情景假设（各假设的逻辑）
     - 计算过程（如 PB × 每股净资产 = 目标价）
  5. 敏感性：关键变量（如商品价格、毛利率）变动对估值的影响
  6. 结论：区间 + 当前位置 + 主要上行/下行触发条件

【小结】估值情景表（悲观/中性/乐观 × 假设 × 目标价）
```

### 步骤4：券商研报分析

研报核心价值在**商业逻辑、客观信息、风险提示**，而非盈利预测数字。

**写作格式**：

```
【结论提要】覆盖频率、主流观点、与本文判断的一致/分歧，一句话

【详细调研】
  1. 覆盖概况：近期有哪些机构、评级、目标价；长期无覆盖本身也是信号
  2. 商业逻辑（逐条展开，非罗列）
     - 行业供需框架、竞争格局、公司定位
     - 研报推理链：前提 → 推导 → 结论，标注可长期有效的框架
  3. 客观信息：产能、成本、产业链、政策等可交叉验证的数据
  4. 风险提示：原材料/价格/政策/公司特有，哪条最具前瞻性
  5. 与本文交叉验证：研报观点与自有调研的一致/矛盾点及原因
  6. 盈利预测与目标价：仅作参考，说明假设与当前现实的偏差

【小结】研报三要素表（商业逻辑 / 客观信息 / 风险）
```

盈利预测、目标价仅作参考。同时记录研报覆盖频率——"长期无覆盖"本身是重要信号。

## 三、调研流程（两阶段）

### 阶段一：初稿调研 → 仅产出 MD

1. 按步骤1-4完成标的本体调研
2. 数据存入 `data/{类别}/{名称}/`
3. 产出 **MD 初稿**：`output/{YYYYMMDD}-{简称}-调研报告-v1.MD`
4. **此阶段不产出 HTML**

### 阶段二：Review 复核 → 补充后产出 HTML

初稿 MD 完成后，**必须执行一轮 Review**：

#### Review 步骤

1. **识别核心关联标的**：从产业链上下游提取重要商品/行业/个股
   - 商品类（如天然橡胶、合成橡胶、原油等）→ 存入 `data/商品/{名称}/`
   - 下游龙头个股（如轮胎赛轮、玲珑等）→ 存入 `data/个股/{名称}/` 或 `data/行业/{名称}/`
   - 判断标准：直接影响标的价格/利润的核心环节，占比>5%或战略意义重大

2. **对关联标的重启一轮调研**（同样采用「结论先行 + 详细展开」，不可只写一行结论）

3. **交叉验证**：用关联标的调研结论回头检验初稿中的行业判断

4. **补充修订 MD**：在初稿基础上新增「关联标的 Review」章节，升级为 `v2`（或同版本覆盖）

5. **产出 HTML**：Review 完成后才生成 `output/{YYYYMMDD}-{简称}-调研报告-v{版本号}.html`

#### Review 产出清单

```
data/商品/天然橡胶/     ← 期货价格、供需、趋势
data/商品/合成橡胶/     ← 如适用
data/个股/赛轮轮胎/     ← 下游龙头，如适用
output/...-调研报告-v2.MD   ← 含 Review 补充
output/...-调研报告-v2.html ← Review 后才产出
```

### 报告必备章节

每章均须含 **【结论提要】** + **【详细调研】**（见第二节写作原则），不可只有表格和判断标记。

1. 公司基本情况（简介/产品/产业链位置/经营模式）
2. 财务分析（核心指标表 + **亏损/盈利原因的逻辑拆解** + 资产负债亮点）
3. 行业分析（概况 → 上游逐项 → 竞争格局 → 下游逐项 → 行业趋势）
4. 估值分析（方法选择理由 + 推算过程 + 同行对比 + 情景敏感性）
5. 券商研报分析（覆盖概况 + 商业逻辑展开 + 风险 + 交叉验证）
6. 综合评估（SWOT 四象限，每项须有论据非空泛形容词）
7. 投资结论（估值区间 + 评级 + 适合投资者 + 关键观察指标 + **触发条件**）
8. **关联标的 Review**（阶段二：核心商品/下游龙头，每项结论先行 + 详细调研 + 对主标的的传导）
9. **参考资料与链接**（所有引用汇总）
